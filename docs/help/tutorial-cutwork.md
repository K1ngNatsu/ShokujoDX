# Tutorial: cutwork

In this tutorial you make a round hole in the fabric with the cutting
needles of a cutwork kit: a running line that holds the fabric, cut
lines, and a satin edge over the cut.

A cutwork kit has four needles with blades, each in one direction. The
machine sews the cut lines with them, so it cuts the fabric in the hoop.

## Open the start design

Click [Open the start design](sample:cutwork-circle). It has a navy
circle of 20 mm (a running line): the edge of the hole. It sews first and
holds the fabric while the needles cut.

## Make the cut lines

The cut lines go on the same circle, so you make them from a copy of it.

1. Click **Edit > Select > Select All**, then **Edit > Clipboard > Copy**
   and **Edit > Clipboard > Paste**. The copy is selected.
2. Click **Specialty > Cutwork > Cutwork**. The **Cutwork** window opens.
3. At **Kit**, select **Bernina** (or the kit of your machine). The window
   shows the four needles and their directions.
4. Keep **Cut spacing** at 1 mm.
5. Click **Make cut lines**. The copy of the circle becomes four cut
   lines: each part of the circle goes to the needle whose blade has its
   direction. Each needle is a color, named for example "Cutwork needle 2
   (/)", so the machine stops to change the needle.

![The Cutwork window](cutwork-window)

6. Close the **Cutwork** window.

## The satin edge

1. Click **Edit > Clipboard > Paste** again. A second copy of the circle is
   selected, at the end of the sew order.
2. In Object Properties, set **Outline Type** to **Satin**. The circle sews
   as a satin of 3 mm over the cut edge.
3. Click **View > Show > Thread Look**, and select **Thread Look** in its
   menu.

![The running line, the cut lines and the satin edge](cutwork-stitches)

The design sews in this order: the running line, the four cut lines
(four needle changes), and the satin edge that covers the edge of the
fabric.

## If it does not look right

- **Make cut lines is gray.** Select the line to cut first.
- **The cut piece falls out where it must stay.** Leave a small gap in
  the cut line there.
- **The edge frays.** Make the satin wider, so that it covers the cut
  and the running line.

How each machine finds the cutting needles in its file is not public, and
the files are not tried on a machine yet. Test them on scrap fabric
first.
