# Cutwork

Machines with a cutwork kit (four needles with blades) cut the fabric
inside a design, for example for Richelieu work or eyelets.
**Specialty > Cutwork** makes the selected lines into cut lines.

## Make cut lines

1. Draw the lines where the fabric is cut (Digitize > Line).
2. Select them, then click **Specialty > Cutwork**.
3. Choose the **Kit**: Bernina; Brother and Baby Lock; Husqvarna Viking
   and Pfaff; Janome. The program takes the brand of the machine of the
   design when it can.
4. Set the **Cut spacing**: the distance between two cuts of the needle
   along the line.
5. Click **Make cut lines**.

## How the cut lines sew

- Each blade cuts in one direction (level, `/`, upright, `\`). Each part
  of a line goes to the needle whose blade has its direction.
- Each needle is a color, named for example "Cutwork needle 2 (/)", so the
  machine stops to change the needle.
- The cut lines have no lock stitches, and the needle lifts between the
  parts.

## A cutwork design

1. Sew a running line round each cut first, so the fabric does not move.
2. Sew the cut lines.
3. Sew a satin border over the cut edge after.
4. Leave small gaps in a cut line where a cut piece must stay on the
   fabric.

How each machine finds the cutting needles in its file is not public,
and the files are not tried on a machine yet. Test them on scrap fabric
first.
