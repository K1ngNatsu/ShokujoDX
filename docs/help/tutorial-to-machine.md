# Tutorial: from the computer to the machine

In this tutorial you sew the badge of the first tutorial on your
embroidery machine. You learn how the program knows your machine, which
file your machine reads, and how to prepare a test sew-out.

You need:

- your embroidery machine, and a hoop of 100 × 100 mm or larger;
- a USB stick that your machine reads;
- a piece of firm woven fabric (cotton or denim), larger than the hoop;
- tear-away stabilizer;
- a new embroidery needle, size 75/11;
- embroidery thread in two colors, and bobbin thread.

## Open the badge

Click [Open the badge](sample:first-badge). It is the badge of the first
tutorial, so you can also start here.

## Set your machine and your hoop

1. Click the **Design** tab. The panel **Machine and Hoop** shows the
   machine and the hoop of the design.
2. In the **Machine** list, select your machine. If your machine is not
   in the list, select the generic machine of its file format.
3. In the **Hoop** list, select the hoop that you use.

![The Machine and Hoop panel](to-machine-machine-hoop)

The machine sets the file format, the longest stitch and the sew time.
The canvas shows the sewing field of the hoop, and the design must be in
it. The program keeps your machine and your hoop for new designs.

## Write the machine file

1. Put the USB stick into the computer.
2. Click **Design > Output > Send to USB**. The first time, choose the
   USB stick and a folder on it. The program writes the machine file in
   the format of your machine, then reads it back to check it.

If your machine has no USB port, click **Design > Output > Export**. The
**Export machine file** window shows the format, the size, the stitches,
the colors and the sew time. Click **Export…**, save the file, and send
it to the machine as its manual tells you.

![The Export machine file window](to-machine-export)

## Prepare the machine

1. Put in the new needle, as the manual of your machine tells you.
2. Put in a full bobbin of bobbin thread.
3. Thread the machine with the first color.
4. Put the stabilizer under the fabric, and hoop the two together. The
   fabric must be tight and flat. Do not pull it out of shape.
5. Attach the hoop to the machine.

## Sew the badge

1. Put the USB stick into the machine, and open the file of the badge.
   It has the name of the design and the extension of the format (for
   example `.vp3`, `.pes` or `.dst`).
2. Make sure that the machine shows the badge in the middle of the hoop.
3. Start the machine. Stay near it.
4. The machine stops after the gold fill. Thread the second color, and
   start the machine again.
5. When the machine stops at the end, remove the hoop. Take the fabric
   out of the hoop, and tear away the stabilizer round the badge.

## Check the sew-out

- The fill covers the fabric, and it is flat.
- The border covers the edge of the fill, with no gap.
- On the back, the bobbin thread shows in the middle of the border, and
  the top thread shows on each side of it. Then the thread tension is
  good.

## If it does not look right

- **A gap between the fill and the border.** The fabric moved in the
  hoop. Hoop it tighter, or use a firmer stabilizer. See [Embroidery
  basics](embroidery-basics).
- **The machine does not show the file.** The format or the folder is
  not correct for the machine. Make sure that the **Machine** list shows
  your machine, and see [Questions and problems](troubleshooting).
- **Loops of top thread, or bobbin thread on the top.** The top thread
  is not in the tension discs. Lift the presser foot, and thread the
  machine again.
- **The thread breaks.** Put in a new needle, and thread the machine
  again.
