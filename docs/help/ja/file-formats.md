# ファイル形式

## プログラムが書き出すミシンファイル

| 形式 | ミシン | 色 |
|---|---|---|
| DST | Tajima、ほとんどの多針ミシン | なし |
| VP3 | Husqvarna Viking、Pfaff | あり |
| PES | Brother、Babylock | あり |
| PEC | Brother(PES のミシン部分) | あり |
| EXP | Melco、Bernina | なし |
| JEF | Janome | あり |
| XXX | Singer | あり |
| TBF | Tajima、針と色付き | あり |
| TAP | Happy | なし |
| U01 | Barudan、低速機能付き | なし |

色のない形式では、**デザインを出力**で、ミシンファイルの隣に糸色ファイル(INF、EDR、COL)を書き出せます。TBF と U01 のファイルには各色の針が入ります(**デザイン > 針**を見てください)。DST、TAP、EXP では、ミシンに入力する針の順序が作業シートに書かれます。DST と TAP には糸切りのコードがありません: **デザイン > ミシンの設定**を見てください。

## プログラムが読むミシンファイル

**ファイル > 開く**と**ステッチを挿入**は、これらの形式をステッチのオブジェクトとして読みます:

DST、VP3、PES、PEC、EXP、JEF、XXX、SEW、HUS、SHV、TBF、TAP、DSB、DSZ、10O、100、U01、DAT、EXY、FXY、GT、STX、PHB、PHC、BRO、EMD、INB、JPX、KSM、MAX、MIT、NEW、PCD、PCQ、PCS、PCM、SPX、STC、ZHS、ZXY。

ミシンファイルにあるのは針落ち点で、形ではありません。密度を保ったまま拡大縮小するには、**アートワーク > 変換 > オブジェクトを認識** (設定つきのランニングオブジェクト、サテンコラム、フィル) か**輪郭を認識** (領域のフィル) を使います。

## Ink/Stitch のファイル

Ink/Stitch は設定を SVG ファイルに保存します。**ファイル > 開く**で Ink/Stitch の SVG ファイルを新しいデザインとして開き、**アートワークを読み込み**でそのオブジェクトを開いているデザインに追加します。図形は、ステッチの種類と設定を持つオブジェクトになります:

- フィル: タタミ、輪郭、ガイド、円形、ミアンダー、クロスステッチ、線形グラデーション。角度、列の間隔、ステッチの長さ、アンダーレイつき。
- サテンコラム: レールと横棒、間隔、縮み補正、アンダーレイ。
- 線: ランニング、ビーンステッチ、ジグザグ、リップル、手動のステッチ。
- コマンド: 糸切り、停止、開始点と終了点、ターゲット点。Ink/Stitch が縫わない図形やレイヤーは、ベクターオブジェクトになります。

糸の色は図形の色です。ファイルがプログラムのカラーチャートと同じ糸パレットを指定していると、糸にその名前と番号が付きます。プログラムが読まない設定は、ファイルを開いた後に表示されるメモに出ます。

**デザイン > Ink/Stitch 用にエクスポート** (ファイルメニューにもあります) で、デザインを Ink/Stitch の SVG ファイルとして書き出します: フィル、サテンコラム、線、文字 (文字の部分)、アップリケ (配置線、仮止め線、カバーのコラム。各段階の後に停止) を、設定とコマンドつきで書き出します。Ink/Stitch にないオブジェクトと設定はメモに出ます。**文字 > フォント > Ink/Stitch フォント…** で Ink/Stitch の文字フォントを変換します: [文字](lettering) を参照してください。

## ほかのファイル

| ファイル | 読む | 書く | 用途 |
|---|---|---|---|
| EMBPROJ | はい | はい | このプログラムのプロジェクト: すべてのオブジェクトと設定。 |
| SVG | はい | はい | ベクターのアートワークと Ink/Stitch のデザインを読み込み、輪郭、デザイン画像、カッターファイルを書き出し。 |
| PDF | はい | はい | ベクターのアートワークを読み込み、作業シート、図案、テンプレートを書き出し。 |
| AI, EPS, PS, EMF, WMF | はい | EMF | ベクターのアートワーク。 |
| CDR | いいえ | いいえ | 公開された仕様がありません。SVG、PDF、EPS で保存してください。 |
| PNG, JPEG, BMP, TIFF, GIF | はい | PNG | 背景の画像を読み込み、デザイン画像を書き出し。 |
| DXF | いいえ | はい | アップリケのカッターファイルとラインストーンのテンプレート。 |
| CSV | はい | はい | 糸チャートとチーム名を読み込み、デザインのプロパティとデザイン一覧を書き出し。 |
| GPL | はい | いいえ | 糸チャート(GIMP のパレット)。 |
| EMBFONT, BDF, FON | はい | EMBFONT | 刺しゅうフォントとアルファベット、ビットマップフォント。 |
| TTF, OTF | はい | いいえ | コンピューターの TrueType と OpenType のフォント。 |
| ZIP | はい | はい | アセットのパッケージ、メールで送信のファイル。 |

## ミシンと形式の名前

このプログラムのミシン、ファイル形式、糸のブランドの名前は、それぞれの所有者の商標です。プログラムがどのファイルを読み書きするかを示すだけです。メーカーはこのプログラムを試験も承認もしていません。新しいデザインは、まず端切れで試してください。
