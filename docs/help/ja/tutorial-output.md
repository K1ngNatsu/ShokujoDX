# チュートリアル: 生産用の出力

このチュートリアルでは、生産に必要なすべてのファイルを 1 回で作ります: ミシンファイル、作業シート、デザインの画像です。

## デザインを出力

1. デザインを開きます。
2. **デザイン > デザインを出力**をクリックします。
3. フォルダーとファイルを選択します: ミシンの形式、生産作業シート(PDF)、承認シート(PDF)、デザインの画像(3D の糸表示の PNG)などです。プログラムは選んだ内容を次回のために覚えます。
4. **出力**をクリックします。**エクスポート**パネルに進み具合が表示されます。

## 生産作業シート

作業シートは、デザインの縫い方をオペレーターに伝えます:

- デザインのサイズ、ステッチ数、縫製時間。
- 枠、ミシンへの取り付け方、枠の中のデザインの位置。
- 各色とその糸、各停止(たとえばアップリケ用)。
- デザインの画像。
- ラインストーンの場合は、作業の順序。

**デザイン > 印刷プレビュー**で、印刷する前に作業シートを確認できます。

## USB へ送信

**デザイン > USB へ送信**は、ミシンファイルを USB メモリの、ミシンのフォルダーに書き込みます。初回は、メモリとフォルダーを選択します。

## 多くのデザインを一度に

**デザイン > 一括出力**は、多くのデザインのファイルを作ります。デザインライブラリ(デザインの横の**ライブラリー**タブ)も、選択したデザインを出力できます。[デザインライブラリとクリップアート](library)を見てください。
