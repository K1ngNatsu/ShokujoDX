# キルティング

**特殊 > キルティング**で、キルティングウィンドウを開きます。3 つの部分があります: **エコー**、**背景**、**キルトブロック**です。キルティングのステッチは線なので、速く縫え、キルトが柔らかいままです。

## エコー

選択した形の周りに、ある距離で、1 本の線としてつながった線を付けます:

- **距離**: 形から最初の線までの距離。
- **間隔**: 2 本の線の間の距離。
- **線**: 線の数。
- **トリプルステッチ**: 各ステッチを 3 回縫い、線がよく見えるようにします。

ボーダーの形(ほかを囲むフィルかベクター)も選択すると、線はその縁で止まり、ある線から次の線への移りはボーダーに沿います。**エコーラインを追加**をクリックします。

## 背景

選択した形とアップリケの周りの領域を、スティップルかメアンダーのフィルで埋めます。周りに隙間を空けるので、形が浮き上がって見えます:

- **パターン**: **スティップル**、または正方形、三角形、六角形のメアンダー。
- **間隔**: フィルの線の間の距離。
- **隙間**: 形とフィルの間の距離。
- **余白**: ボーダーの形がない場合に、矩形が形の外へどれだけ出るか。

領域は、選択したボーダーの形、なければ形を囲む矩形です。**背景を追加**をクリックします。

## キルトブロック

選択した線をブロック全体に繰り返すか、メアンダーで覆い、ブロックの縁で切ります:

- **パターン**: **選択した線**、またはメアンダー。
- ブロックの**幅**と**高さ**(最初は 300 × 300 mm)。
- **横の隙間**と**縦の隙間**: 横に並んだ 2 つのコピーの間と、2 つの列の間の距離。横が 0 なら、コピーがつながります。
- **ブロックのまわりの線**。

**キルトブロックを作る**をクリックします。

終点が始点と同じ高さのパターンを作り、横の隙間を 0 にすると、コピーがつながって長い線になります。枠より大きいブロックは枠入れで縫います([枠より大きいデザイン](hooping)を見てください): 2 つの枠入れが接する場所で線を切るので、隙間なくつながります。

## ヒント

- キルティング用の糸と針、しっかり押さえる枠、またはキルティングフレームを使います。
- キルトのサンドイッチ(表布、キルト綿、裏布)は平らに枠に張ります。引っ張らないでください。
- オブジェクトのプロパティのフィルの種類「メアンダー」でも、1 つの形をメアンダーで埋められます。[ステッチの種類](stitch-types)を見てください。
