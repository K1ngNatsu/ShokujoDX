# チュートリアル: パソコンからミシンへ

このチュートリアルでは、最初のチュートリアルのバッジを刺しゅうミシンで縫います。プログラムがミシンをどう知るか、ミシンがどのファイルを読むか、試し縫いをどう準備するかを学びます。

用意するもの:

- 刺しゅうミシンと、100 × 100 mm 以上の枠
- ミシンが読める USB メモリー
- 枠より大きい、しっかりした織物の布(綿またはデニム)
- 破るタイプの安定紙
- 新しい刺しゅう針(75/11)
- 2 色の刺しゅう糸と下糸

## バッジを開く

[バッジを開く](sample:first-badge)をクリックします。最初のチュートリアルのバッジなので、ここから始めることもできます。

## ミシンと枠を設定する

1. **デザイン**タブをクリックします。**ミシンと枠**パネルに、デザインのミシンと枠が表示されます。
2. **ミシン**のリストで、お使いのミシンを選択します。リストにない場合は、そのファイル形式の汎用ミシンを選択します。
3. **枠**のリストで、使う枠を選択します。

![ミシンと枠パネル](to-machine-machine-hoop)

ミシンによって、ファイル形式、最長のステッチ、縫製時間が決まります。キャンバスには枠の縫製範囲が表示され、デザインはその中に入っている必要があります。プログラムは、ミシンと枠を新しいデザインのために覚えておきます。

## ミシンファイルを書き出す

1. USB メモリーをパソコンに差し込みます。
2. **デザイン > 出力 > USB へ送信**をクリックします。初回は、USB メモリーとその中のフォルダーを選びます。プログラムはミシンの形式でミシンファイルを書き出し、読み戻して確認します。

ミシンに USB ポートがない場合は、**デザイン > 出力 > エクスポート**をクリックします。**ミシンファイルをエクスポート**ウィンドウに、形式、サイズ、ステッチ、色、縫製時間が表示されます。**エクスポート…**をクリックしてファイルを保存し、ミシンの説明書のとおりにミシンへ送ります。

![ミシンファイルをエクスポートウィンドウ](to-machine-export)

## ミシンを準備する

1. ミシンの説明書のとおりに、新しい針を付けます。
2. 下糸を巻いたボビンを入れます。
3. 1 色目の糸をミシンに通します。
4. 安定紙を布の下に置き、2 枚を一緒に枠に張ります。布はぴんと平らに張ります。布を引っぱって形を変えないでください。
5. 枠をミシンに取り付けます。

## バッジを縫う

1. USB メモリーをミシンに差し込み、バッジのファイルを開きます。ファイル名はデザインの名前に形式の拡張子が付いたものです(例: `.vp3`、`.pes`、`.dst`)。
2. ミシンにバッジが枠の中央に表示されていることを確認します。
3. ミシンをスタートします。そばにいてください。
4. 金色のフィルのあとでミシンが止まります。2 色目の糸を通し、ミシンをもう一度スタートします。
5. 最後にミシンが止まったら、枠を外します。布を枠から外し、バッジの周りの安定紙を破り取ります。

## 縫い上がりを確認する

- フィルが布を覆い、平らになっている。
- 縁取りがフィルの端をすき間なく覆っている。
- 裏で、縁取りの中央に下糸が見え、その両側に上糸が見える。このとき糸調子は良好です。

## うまくいかないとき

- **フィルと縁取りの間にすき間がある。** 布が枠の中で動きました。もっときつく張るか、しっかりした安定紙を使います。[刺しゅうの基本](embroidery-basics)を参照してください。
- **ミシンにファイルが表示されない。** 形式かフォルダーがミシンに合っていません。**ミシン**のリストにお使いのミシンが表示されていることを確認し、[質問と問題](troubleshooting)を参照してください。
- **上糸のループ、または表に下糸が出る。** 上糸が糸調子皿に入っていません。押さえを上げて、ミシンにもう一度糸を通します。
- **糸が切れる。** 新しい針に替え、ミシンにもう一度糸を通します。
