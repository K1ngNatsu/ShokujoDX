# チュートリアル: キルトブロック

このチュートリアルでは、ハートの周りをエコーラインでキルティングし、その周りの空間をスティップルの背景で埋め、波の線からキルトブロックを作ります。

## スタートデザインを開く

[スタートデザインを開く](sample:quilt-heart)をクリックします。赤いハート(フィル)と、その下に赤い波の線があります: 波の線はキルトブロックのパターンです。

## 生地

1. **デザイン > 生地とスタイル > 生地**をクリックします。
2. **生地**のリストで**キルト (トップ、キルト芯、裏布)**を選択し、**適用**をクリックします。キルトの層は厚くて柔らかいです: プログラムはキルティングの線に長いステッチを使い、3D 表示では線の間でキルト芯がふくらんで見えます。

## エコーライン

エコーラインは、形の輪郭に沿って外側へ 1 本ずつ並ぶ線で、糸切りのない 1 本の線として縫われます。

1. ハートをクリックして選択します。
2. **特殊 > キルティング > キルティング**をクリックします。**キルティング**ウィンドウが**エコー**で開きます。
3. **距離**を 3 mm(ハートから最初の線まで)、**間隔**を 5 mm(線と線の間)、**線**を 3 にします。
4. **エコーラインを追加**をクリックします。

![キルティングウィンドウ](quilt-window)

## 背景

スティップルの背景は、形の周りの空間を、自分と交わらずにさまよう線で埋めます。形はその上に浮き上がって見えます。

1. もう一度ハートをクリックして選択します。
2. ウィンドウの**背景**をクリックします。パターンは**スティップル**のままにします。
3. **隙間**を 16 mm にします: スティップルはエコーラインの外側から始まります。
4. **背景を追加**をクリックします。

## キルトブロック

キルトブロックは、選択した線を長方形の上に繰り返します。枠より大きいブロックは枠入れで縫い、2 つの枠入れの線がつながります。

1. 波の線をクリックして選択します。
2. ウィンドウの**キルトブロック**をクリックします。
3. **幅**を 110 mm、**高さ**を 50 mm にします。
4. **キルトブロックを作る**をクリックします。波がブロック全体に繰り返され、周りに線が付きます。
5. ウィンドウを閉じます。**表示 > 表示 > 糸表示**をクリックし、そのメニューで**糸表示**を選びます。

![エコーライン、スティップル、キルトブロックの付いたハート](quilt-stitches)

## うまくいかないとき

- **エコーラインを追加が灰色になっている。** 先にハートを選択します。
- **スティップルがエコーラインを覆う。** **隙間**を、最後のエコーラインの距離より大きくします。
- **ブロックの波の間に隙間がある。** **横の隙間**を 0 にし、両端が同じ高さにある線を描きます。
