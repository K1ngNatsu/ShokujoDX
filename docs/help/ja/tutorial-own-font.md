# チュートリアル: 自分の刺しゅうフォント

このチュートリアルでは、TrueType フォントから刺しゅうフォントを作り、縫って確かめるために文字のテストシートを作り、1 文字を修正します。

刺しゅうフォントは TrueType フォントよりきれいに縫えます: 文字は一度だけ作られ、コラム、縫い順、端が確認されています。また、サイズの範囲と品質スコアがあります。

フォントのライセンスで変更が許されているか確認してください。予約フォント名(Reserved Font Name)のある OFL フォント(SIL Open Font License)には、新しい名前が必要です。

## フォントを変換する

1. **文字 > 文字 > フォント**をクリックします。**フォント**ウィンドウが開きます。
2. **TrueType** をクリックします: 一覧に TrueType フォントだけが表示されます。
3. 検索欄に `Graduate` と入力し、一覧の **Graduate** をクリックします。Graduate はプログラムの TrueType フォントです。自分のロゴのフォントも同じように使います。
4. **刺繍フォントに変換…**をクリックします。

![変換の設定](own-font-convert)

5. 刺しゅうフォントの**名前**を入力します。たとえば `Graduate Embroidery` です。
6. **ステッチの種類**は**自動**のままにします: サテンコラムと、サテンには太すぎる線のためのフィルです。**フィル**は、大きい文字用のフィルフォントを作ります。
7. **糸切りを少なく**はオンのままにします: プログラムは、各文字の縫い順を、糸切りが最も少なくなるように決めます。変換には時間がかかります: 速いコンピューターで数秒、遅いコンピューターでは 1 分以上です。
8. **変換**をクリックします。進行状況のバーに手順が表示されます。それからウィンドウに「刺繍フォント Graduate Embroidery の準備ができました。」と、その品質スコアが表示されます。

新しいフォントは、自分のフォントのフォルダーに入り、フォントの一覧に表示されます。プログラムの新しいバージョンでも残ります。

## テストシートを作る

テストシートには、フォントのすべての文字が、最小、中央、最大のサイズで並びます。そのフォントでたくさんのテキストを縫う前に、実際に使う生地でテストシートを縫ってください。

1. **フォント**ウィンドウでフォントを選択したまま、**テストシート…**をクリックします。**フォントのテストシート**ウィンドウが開きます。
2. **文字**で**大文字**を選択します。(**文字、数字、記号**では、もっと大きいシートになります。)
3. **テストシートを作成**をクリックします。シートが新しいデザインとして開きます。

![大文字のテストシート](own-font-sheet)

糸表示で文字を見てから、シートを縫います。線と線の間のすき間、最小サイズで細すぎるコラム、最大サイズでゆるいサテンがないか確認します。

## 文字を修正する

1 つの文字がきれいに縫えないときは、その文字を修正します。修正は、フォントをもう一度作っても残ります。

1. **新規**をクリックします: 文字は新しいデザインに入ります。
2. **文字 > 文字 > アルファベット**をクリックします。**アルファベット**ウィンドウが開きます。**文字の修正**はその下の部分にあります。
3. **フォント**を選択し、**文字**に修正する文字を入力します。たとえば `A` です。
4. **文字を置く**をクリックします。文字のオブジェクトが、縫い順のまま、ガイドの間でデザインに入ります。

![修正のために置いた文字](own-font-letter)

5. オブジェクトを変更します: その順序(縫い順パネル)、コラムの方向(**編集 > 線とコラム > 方向を反転**)、形(**デジタイズ > 選択 > 形状編集**)、設定(オブジェクトのプロパティ)。
6. 文字のすべてのオブジェクトを選択し、**修正を保存**をクリックします。

**修正を削除**で、フォントの元の文字に戻ります。修正は、自分のフォントのフォルダーにあるファイルです(**ファイルを表示**)。

## うまくいかないとき

- **変換が灰色になっている。** 先に名前を入力します。
- **品質スコアが低い。** サテンコラムには細すぎる線や太すぎる線があると、スコアが下がります。太いフォントには**フィル**を試すか、フォントをそのサイズの範囲の中だけで使います。
- **テストシートが枠より大きい。** サイズや文字を減らすか、**行の幅**を小さくします。
