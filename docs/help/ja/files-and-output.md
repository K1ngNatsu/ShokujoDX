# ファイルと出力

## プロジェクトとミシンファイル

- **プロジェクト**(`.embproj`)は、すべてのオブジェクトと設定を保ちます。**ファイル > 保存**(Ctrl+S)で保存し、**名前を付けて保存**で新しい名前で保存します。
- **ミシンファイル**(DST、PES、VP3 など)には、ステッチ、色(ほとんどの形式)、ミシン機能だけが入ります。変更するためにプロジェクトを残してください。
- **ファイル > 開く**で、プロジェクト、またはミシンファイルをステッチのオブジェクトとして開きます。プログラムは約 40 のミシン形式を読みます。[ファイル形式](file-formats)を見てください。
- **ファイル > 最近のデザイン**で、前に使ったデザインを開きます。
- **ファイル > 閉じる**と**すべて閉じる**でデザインを閉じます。変更のある各デザインについて、プログラムが先に尋ねます。

## バックアップ

プログラムは、変更のある各デザインのバックアップを 2 分ごとに保存します(**オプション > 自動バックアップ**)。プログラムが止まったときは、次の起動時に**デザインを復元**のウィンドウにバックアップが表示されます。クラッシュレポートは設定の `crashes` フォルダーに入ります。**ヘルプ > バージョン情報**に場所が表示されます。

## ミシンファイルをエクスポートする

**デザイン > エクスポート**(Ctrl+E、またはファイル > ミシンファイルをエクスポート)で、ミシンのためのステッチを書き出します。ウィンドウには、**形式**(既定はミシンの形式)、枠、サイズ、ステッチ、色、糸切り、停止、配色、縫製時間が表示されます。

| 形式 | ミシン |
|---|---|
| DST | Tajima、ほとんどの多針ミシン |
| VP3 | Husqvarna Viking、Pfaff |
| PES | Brother、Babylock |
| PEC | Brother(PES のミシン部分) |
| EXP | Melco、Bernina |
| JEF | Janome |
| XXX | Singer |
| TBF | Tajima、針と色付き |
| TAP | Happy |
| U01 | Barudan、低速機能付き |

## USB へ送信

- **デザイン > USB へ送信**で、ミシンの形式のデザインをミシンの USB スティックに書き込み、読み戻して確認します。最初に、スティックとフォルダーを選びます。
- **送信先…**で、スティックとフォルダーを選び直します。プログラムはミシンごとにそれを保ちます。

## メールで送信

**デザイン > メールで送信**で、ミシンファイル、プロジェクト、画像を、デザインの隣の 1 つの zip ファイルに入れ、メールプログラムを開きます。zip ファイルをメッセージに添付してください。

## デザインを出力

**デザイン > デザインを出力**で、生産のすべてのファイルを 1 回で、1 つのフォルダーに作ります:

- **ミシンファイル**(1 つ以上の形式)とプロジェクトファイル。
- **生産作業シート**と**承認シート**(PDF)。必要なら**作業シートにバーコード**を付け、**用紙**のサイズを設定します。
- **デザイン画像**(PNG。必要なら 3D の糸表示)と(SVG)。
- **デザインのプロパティ**(CSV)。
- DST やほかの色のない形式のための**糸色ファイル**(INF、EDR、COL)。
- ストーンのあるデザインのための**ラインストーンのテンプレート**(SVG、PDF)。

プログラムは選んだ内容を次回のために保ちます。作業はキューに入り、**エクスポート**パネルに表示されるので、作業を続けられます。[チュートリアル: 生産用の出力](tutorial-output)を見てください。

## 作業シートと承認シート

**デザイン > 印刷プレビュー**で、**生産作業シート**と**承認シート**をページごとに表示します。**作業シート用メモ**で、たとえば仕事、お客様、生地、針などの文字を追加します。**PDF を保存**でシートを書き出します。印刷するには、PDF ビューアーから PDF を印刷します。

作業シートには、サイズ、ステッチ、縫製時間、枠とデザインの位置、各色と停止、生地、裏打ちと表打ち、画像、ラインストーンの作業順があります。

## 一括出力

**デザイン > 一括出力**で、多くのプロジェクトファイルとミシンファイルについて、デザインを出力のファイルを一度に作ります。デザインライブラリでも、選択したデザインを出力できます。

## ほかのファイル

- **デザイン > SVG をエクスポート**: デザイン画像を SVG で。ステッチを糸の色の線として、実寸で。
- **アートワーク > アウトラインをエクスポート**: 形を SVG または EMF のパスで。
- **デジタイズ > カッターファイル**: アップリケのピースの切り線(SVG、DXF)。
- **特殊 > テンプレート**: ラインストーンのテンプレート(SVG、DXF、PDF)。
- **特殊 > 図案**: クロスステッチの図案(PDF)。
- **デザイン > 枠のテンプレート**: 枠のフィールドの実寸(PDF)。

## ファイルマネージャーの画像

インストール後は、ファイルマネージャー(Explorer、Finder、Linux のファイルマネージャー)が、各デザインファイルの画像をアイコンとして表示します: プロジェクトとミシンファイルです。

## ヒント

- ミシンの形式を確認してください(デザインタブのミシンの一覧)。ほとんどの家庭用ミシンは、自分の形式だけを読みます。
- USB スティックのフォルダーを確認してください。USB へ送信は、ミシンのフォルダーを使います。
- ミシンがファイルを読まない場合は、[質問と問題](troubleshooting)を見てください。
