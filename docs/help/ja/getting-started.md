# はじめに

ShokujoDX は刺しゅうデザインを作ります。形を描いたり、文字を入力したり、画像から始めたりすると、プログラムがステッチを作ります。そのあと、刺しゅうミシン用のファイルを書き出します。

刺しゅうが初めての場合は、先に[刺しゅうの基本](embroidery-basics)を読んでください。手を動かして覚えるには、[チュートリアル: 画像からワッペン](tutorial-patch)から始めてください。

## スタートページ

スタートページはプログラムの起動時に表示されます。次のものがあります:

- **新しいデザイン**、**テンプレートから新規**、**開く**、**画像からデザイン**。
- 最近のデザイン(それぞれ画像付き)。クリックすると開きます。
- チュートリアルと、質問を入力できる欄。
- **シンプルモード**と**文字キオスク**(店舗向け)。

**ヘルプ > スタートページ**でもう一度表示します。起動時に表示しない場合は、**起動時に表示**のチェックを外してください。

ファイルをウィンドウにドラッグして開くこともできます。デザインやミシンファイルは新しいタブで開き、SVG や PDF はデザインに入り、画像は背景画像になります。

## ウィンドウ

- **ファイルボタン**(左上)はファイルメニューを開きます: 新規、開く、保存、読み込み、エクスポート、オプション、終了。その隣に**新規**、**開く**、**保存**、**元に戻す**、**やり直し**があります。
- **リボン**にはコマンドがタブごとにあります。下の「コマンドの場所」を見てください。
- リボンの下の**デザインのタブ**は、開いている各デザインを示します。**+** で新しいデザインを作ります。
- 中央の**キャンバス**は枠とデザインを表示します。[キャンバスと選択](canvas)を見てください。
- 右側の**パネル**は、選択したオブジェクト(オブジェクトのプロパティ)、縫い順(縫い順)、糸、スタイル、デザイン情報などを表示します。各パネルは × で閉じます。**表示 > パネル**でもう一度開きます。
- リボンの下の**プロパティバー**には、使用中のツールの設定があります。たとえば新しい線のステッチの長さです。
- 下の**ステータス行**は次にすることを示し、オブジェクト、色、ステッチ、糸切りの数、縫製時間、ズームを表示します。

## コマンドの場所

リボンの各タブには、1 種類の作業のコマンドがあります:

| タブ | 内容 |
|---|---|
| デジタイズ | 選択ツールと、線、フィル、コラム、形、アップリケを描くツール。縁、ボタンホール、ブレンド。 |
| 文字 | 文字、フォント、アルファベット、モノグラム、チーム名、キーボードデザイン、キオスク。 |
| アートワーク | 画像(画像からデザイン、背景画像、トレース、クリックで刺しゅう)とベクターアートワーク(読み込み、描画、変換、形の操作、縁取り、オフセット)。 |
| 特殊 | クロスステッチ、ラインストーン、カットワーク、キルティング、パフ、レイダウン。 |
| 編集 | コピーと貼り付け、選択、分割と結合、形と線の変更、ステッチの種類、ミシンの機能。 |
| 配置 | 回転、反転、整列、間隔、コピー、グループ、ロック、縫い順。 |
| 色 | 糸、糸チャート、カラーウェイ、生地の色。 |
| 表示 | キャンバスに表示するもの、ステッチプレーヤーとステッチカーソル、フィルター、ズーム、作業領域。 |
| デザイン | ミシン、枠、生地、スタイル、デザインライブラリ、テンプレート、繰り返し、製品、出力ファイル。 |
| 枠入れ | 枠より大きいデザイン。 |
| ヘルプ | ヘルプのトピック、チュートリアル、スタートページ、シンプルモード。 |

ヘルプには各タブのトピックがあり、そのすべてのコマンドが載っています: ヘルプの目次の**リボン**を見てください。

ウィンドウが狭いときは、リボンのパネルが名前と矢印の付いた 1 つのボタンにたたまれます。ボタンをクリックすると、そのパネルのコマンドが表示されます。タブをダブルクリックするとリボンを隠して広く使えます。タブをクリックすると再び表示します。

## コマンドを検索

- **Ctrl+K** で**コマンドを検索**を開きます: コマンド名の一部を入力し、矢印キーで選んで **Enter** を押します。リボンのすべてのコマンドが、ショートカットとともに入っています。
- **スペース**でリボンの最後のコマンドをもう一度実行します。
- **F6** でキーボードの操作をリボンに移します。**Tab** と **Shift+Tab** でボタン間を移動し、**Enter** で実行し、**Esc** でキャンバスに戻ります。
- スクリーンリーダー(たとえばナレーターや NVDA)はボタンとキャンバスを読み上げます。

## 文字サイズ、コントラスト、言語

**オプション**(表示タブ、またはファイルメニュー)で次を設定します:

- **文字サイズ**: すべての文字とボタンを 90 % から 200 % まで。**Ctrl+Plus**、**Ctrl+Minus**、**Ctrl+0** でも変わります。
- **ハイコントラスト**: 黒または白のパネルと、はっきりした線。
- **言語**: English、Deutsch、Español、日本語。ヘルプのトピックも同じ言語になります(翻訳のないトピックは英語です)。

すべての設定は[オプション](options)を見てください。

## シンプルモード

シンプルモードでは、ツールが少なくなり、ボタンが大きくなります: デザインを描き、文字を入れ、ミシンに送るためのツールです。これらの作業に不要なパネルも隠します。

- オンとオフを切り替えるには、**ヘルプ > シンプルモード**をクリックするか、スタートページかオプションのチェックボックスを使います。
- シンプルモードでは、**表示 > シンプルモード**で再びオフにします。
- シンプルモードのすべてのコマンドは、通常のリボンにもあります。

## デザインを始める前に

1. **デザイン**タブでミシンを選択します。ミシンによってファイル形式が決まります(たとえば Husqvarna Viking は VP3、Brother は PES、ほとんどの業務用ミシンは DST)。
2. **デザイン**タブで枠を選択します。キャンバスに枠が表示されます。キャンバスの上はミシンの奥です。
3. 生地がわかっている場合は、**デザイン > 生地**をクリックします。生地によって、オブジェクトの密度、アンダーレイ、縮み補正が変わります。

[ミシンと枠](machines-and-hoops)と[生地、スタイル、テンプレート](fabrics-and-styles)を見てください。

## 保存と元に戻す

- **Ctrl+S** でデザインをプロジェクトファイル(`.embproj`)として保存します。プロジェクトはすべてのオブジェクトと設定を保持するので、あとで変更できます。
- **Ctrl+Z** で最後の変更を元に戻します。**Ctrl+Y** でやり直します。元に戻すとやり直しのツールチップに、何が変わるかが表示されます。
- プログラムは、変更した各デザインのバックアップを 2 分ごとに保存します。プログラムが止まったときは、次回の起動時にバックアップを提示します。
- ミシンファイル(DST、PES、VP3 など)にはステッチしかありません。変更するには、プロジェクトファイルを残しておいてください。

## ヘルプを見る

- ポインターをボタンの上に置いて待つと、短い説明が表示されます。
- ポインターをボタンの上に置いて **F1** を押すと、そのコマンドのヘルプが開きます。
- ポインターがウィンドウ(たとえばオフセットや文字のウィンドウ)の上にあるときに **F1** を押すと、そのウィンドウのトピックが開きます。
- **ヘルプ > ヘルプ**ですべてのトピックを表示します。検索欄に質問を入力します。たとえば「文字を大きくするには」。答えが最初に表示され、その下に同じ言葉を含むほかのトピックが表示されます。
- トピックのリンクをクリックすると、別のトピックに移ります。**戻る**で前のトピックに戻ります。
- [質問と問題](troubleshooting)によくある問題の答えがあります。
