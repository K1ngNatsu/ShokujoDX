# 用語集

| 用語 | 意味 |
|---|---|
| アップリケ | デザインに縫い付ける布: 配置線、押さえ縫い、カバーのサテン。 |
| 裏打ち | 生地の下の安定紙。ニットにはカットタイプ、織物にはティアタイプ。 |
| ビーンステッチ | 各ステッチを 3 回縫うランニングステッチ(トリプル)で、太い線になります。 |
| ボビン(下糸) | 生地の下の糸。各針落ち点で上糸と絡みます。 |
| 縁取りトレース | オブジェクトの周りの縁や隙間で、下のオブジェクトから切り抜きます。 |
| 色替え | 別の糸を縫うために、ミシンが止まるか、別の針に移ります。 |
| カラーウェイ | デザインの 1 組の色。デザインは複数のカラーウェイを持てます。 |
| コラム | サテンのコラム: 形の一方の辺(レール A)からもう一方(レール B)へ横切るステッチ。 |
| 現在のプロパティ | 新しいオブジェクトに付くステッチの設定。 |
| 密度 | 列やサテンのステッチの間の距離。小さいほど密になります。 |
| 密度マップ | 糸の層によってデザインを色分けする表示。 |
| デジタイズ | 刺しゅうデザインを作ること: 形、ステッチの種類、縫い順、設定。 |
| フィル | 領域を覆うステッチの列。 |
| 枠 | ミシンの上で生地を押さえる枠。フィールドは針が届く範囲です。 |
| 枠入れ | 枠より大きいデザインの 1 つの部分。 |
| ジャンプ | ステッチのない枠の移動。 |
| レイダウン | タオルやフリースのパイルを押さえる、デザインの下の軽いフィル。 |
| 止め縫い | オブジェクトの始めや終わりで糸を留める小さなステッチ。 |
| ミシンファイル | 1 台のミシンのための、デザインの針落ち点と機能(DST、PES、VP3 など)。 |
| モチーフ | 線、コラム、フィルの中で繰り返す小さなステッチの模様。 |
| 針落ち点 | 針が生地を通る場所。 |
| オブジェクト | デザインの 1 つの部分: 線、コラム、フィル、アップリケ、文字など。 |
| プロジェクト | このプログラムのファイル(.embproj)で、すべてのオブジェクトと設定が入ります。 |
| 縮み補正 | ステッチが方向と直角に生地を引き寄せるので、追加する幅。 |
| 合わせマーク | 2 回の枠入れやラインストーンのテンプレートを合わせる十字。 |
| ランニングステッチ | 線に沿って 1 つずつ続くステッチ。 |
| サテン | コラムの辺から辺への滑らかなステッチ。光沢があります。 |
| セット | タータンの 1 回の繰り返しの縞。たとえば K4 R24 K24 Y4。 |
| 縫い順 | オブジェクトを縫う順序。後に縫うオブジェクトが上になります。 |
| 分割 | 長いステッチに追加する針落ち点で、引っかからないようにします。 |
| 安定紙 | 縫う間に生地を支える材料: 裏打ちと表打ち。 |
| ステッチ | 2 つの針落ち点の間の糸。 |
| ステッチカーソル | 1 つのステッチの印で、デザインを 1 ステッチずつ確認します。 |
| ステッチのオブジェクト | ミシンファイルやフォトステッチのステッチで、そのまま縫います。 |
| 停止 | 手で作業できるように、ミシンが止まります。 |
| スタイル | 名前の付いたステッチの設定の組。 |
| 押さえ縫い | カバーのサテンの前に、アップリケの布を押さえるステッチ。 |
| タタミ | 線が見えない模様の、まっすぐな列のフィル。 |
| 糸チャート | 糸のブランドの色の一覧。 |
| 表打ち | タオル、フリース、ベルベットの上に置く水溶性のフィルム。 |
| 渡り縫い | ある部分から次の部分へ移るステッチで、それを覆うステッチの下に入ります。 |
| 糸切り | ミシンが糸を切ります。 |
| アンダーレイ | 上のステッチの下のステッチで、生地を押さえ、上のステッチを持ち上げます。 |
| ベクター | ステッチのない形。変換で刺しゅうにします。 |
