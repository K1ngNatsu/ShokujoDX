# ベクターアートワークとシェイピング

ベクターアートワークは、ステッチのない形です。キャンバスには表示されますが、何も縫わず、ミシンファイルには含まれません。ガイドとして使うか、刺しゅうに変換します。

## アートワークを読み込む

**アートワーク > 読み込み**のパネルは、SVG、PDF、AI、EMF、WMF のファイルを読みます:

- **ベクターとして読み込み**: パスがベクターアートワークになります。あとで変換します。
- **アートワークを読み込み**: パスがすぐに刺しゅうのオブジェクト(フィルと線)になります。
- **線として読み込み**: 各形の輪郭と各ストロークが、ランニングステッチの線になります。
- **ステッチを挿入**は、ミシンファイルのステッチを、ステッチオブジェクトとしてデザインに追加します。

SVG や PDF のファイルをウィンドウにドラッグすることもできます。

## アートワークを描く

**アートワーク > アートワークを描く**をオンにします。すると描画ツール(形、線、フリーハンド、長方形、楕円、星)が、刺しゅうのオブジェクトの代わりにベクターアートワークを作ります。オフにすると、また刺しゅうを描きます。

**ベクター**でアートワークを表示または非表示にします。**ベクターを薄く表示**で薄く表示し、ステッチを目立たせます。

## 変換

ベクターを選択して、次を使います:

- **フィルへ**: 閉じた各形が、穴のあるフィルになります。
- **サテンへ**: 閉じた各形がサテンになります。長い形には中心に沿った回転するコラム、O の輪にはリングのコラム、そのほかの形にはステッチの種類がサテンのフィルが付きます。形の外やほかの部分の上にステッチは出ません。線は、それに沿ったサテンコラムになります。
- **アウトラインへ**: すべてのパスが 1 本のランニングステッチの線になります。

パネルのそのほかのコマンド:

- **ベクターへ**: 選択した刺しゅうのオブジェクトが、ベクターアートワーク(輪郭だけでステッチなし)になります。
- **輪郭を認識**: ステッチオブジェクト(ミシンファイルやフォトステッチから)を、そのステッチが覆う領域のフィルにします。すると拡大縮小しても密度が保たれます。

## シェイピング

シェイピングは、選択した 2 つ以上の形(ベクター、フィル、アップリケ、そのほかの面積のあるオブジェクト)から新しい形を作ります。手前の形は最後に縫う形です。

| コマンド | 結果 |
|---|---|
| 溶接 | 選択したすべての形を 1 つの形にします。 |
| 交差 | 選択したすべての形が覆う領域だけにします。 |
| 除外 | 形が共有しない領域にします。 |
| 結合 | 選択したベクター、または選択したアップリケのオブジェクトを 1 つのオブジェクトにします。 |
| 手前から奥を引く | 手前の形から、ほかの形を切り抜きます。 |
| 奥から手前を引く | 奥の形から、ほかの形を切り抜きます。 |
| 平坦化 | 各形から、手前の形が隠す部分を取り除き、二重に縫われないようにします。 |
| 分割 | 形が重なる場所で形を切り分け、各重なりを手前の形に付けます。 |
| 重なりを除去 | 選択した形を、その下のオブジェクトから切り抜きます。 |

パネルのオプション:

- **元を残す**: 選択したオブジェクトは残り、結果がそのあとに入ります。
- **リンクを保つ**: 平坦化、分割、重なりを除去は、オブジェクトが動くと切り直します。**リンク解除**で選択範囲のリンクを終えます。オブジェクトはそのまま残ります。
- **重なり**: 切った部品が、それを切った形の下にどれだけ入るか。部品の間に生地が見えないようにします。重なりを除去とナイフもこれを使います。

平坦化と重なりを除去では、文字は文字のままです。手前の文字は、その文字の形で下のオブジェクトを切り抜きます。ほかのオブジェクトの下にある文字にはノックアウトが付きます: その文字のステッチは手前のオブジェクトの領域を縫わず、テキスト、フォント、文字はあとから変えられます。ほかのシェイピングのコマンドは文字を使いません。

## 縁取りトレース

**アートワーク > 縁取りトレース**は、選択したオブジェクトの周りに縁、すき間、またはその両方を、その下のオブジェクトから切り抜いて追加します。すき間には生地が見えます。

- **縁取りの幅**、**ステッチ**(コラムの種類、ラン、トリプルラン)、**糸**。
- **縁取りの位置**: オブジェクトの端のどこに縁を置くか。**線の外側**: 縁はオブジェクトの周りを回り、端を少しだけ覆います(生地が見えないように、コラムは端の上に 0.4 mm かかります)。**線の中心**: 縁の中央が端の上にあります。**線の内側**: 縁がオブジェクトの端を覆い、デザインは大きくなりません。
- **縫い順**: **オブジェクト、次に縁取り**または**縁取り、次にオブジェクト**。
- **隙間の幅**: 縁の周り(縁がなければオブジェクトの周り)の、生地が見える場所。

トレースはリンクされたままです: オブジェクトが動くと切り直されます。オブジェクトを選択している間に、ウィンドウで変更します。**縁取りトレースを削除**で、切られたオブジェクトを元に戻します。

オブジェクトとその縁は 1 つのグループなので、クリックするとすべてが選択されます。その 1 つのステッチ(たとえばフィルの種類)を変えるには、それをダブルクリックするか、プロパティパネルの**グループのオブジェクト**の下のボタンをクリックします。分解と結合は、リンクされたオブジェクトには使えません: 先に**アートワーク > リンク解除**を使ってください。

## オフセット

**アートワーク > オフセット**は、選択したオブジェクトの周り(**外側**)または中(**内側**)に、距離をあけてアウトラインを追加します:

- 最初のアウトラインの**距離**、**アウトライン**の数、その間の**間隔**。
- **角**: **丸**、**鋭角**、**切り取り**。
- **作成**: **線**、**ベクター**、または幅のあるサテンの**縁取り**。
- **縁取りの位置**(縁取りの場合): **線の外側**(オブジェクトの中心から離れる方向で、距離 0 の縁がオブジェクトを覆いません)、**線の中心**、**線の内側**(オブジェクトの中心へ向かう方向)。オブジェクトの中のアウトラインでも、外側と内側は同じです。

**縁取りを追加**は同じウィンドウを、最後に使った縁取りの位置で、サテンの縁を 1 つ作る設定で開きます。

## アウトラインをエクスポート

**アートワーク > アウトラインをエクスポート**は、オブジェクトの形を、ベクタープログラムやカッター用の SVG か EMF のパスとして書き出します。アップリケの布片には、**デジタイズ > カッターファイル**を使います。
