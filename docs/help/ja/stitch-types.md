# ステッチの種類

ステッチの種類で、オブジェクトのステッチの模様が決まります。オブジェクトのプロパティで設定するか、**編集 > ステッチの種類**で多くのオブジェクトにまとめて設定します:

- **アウトラインの種類**: 選択した線を普通の線として縫うか、線に沿ったステッチの種類のコラム(幅あり)として縫います。
- **フィルの種類**: 選択したフィルのステッチの種類です。
- **コラムの種類**: 選択したサテンコラムと、幅のある線のステッチの種類です。

変更はそれぞれ 1 回の元に戻す操作になります。一覧の種類の上にポインターを置くと、その働きがわかります。

## 線

ランの種類(プロパティバーとオブジェクトのプロパティ):

| ランの種類 | 縫い方 |
|---|---|
| ラン | 線に沿った均一なステッチ。 |
| バックステッチ | 半歩ずつ 2 回進み 1 回戻る、手縫いのバックステッチのような縫い方。 |
| ステムステッチ | 進むステッチを少し片側にずらしたバックステッチ。手縫いのステムステッチのようです。 |
| スカルプチャーラン | トリプルと 1 本のステッチを交互に縫い、線がビーズをつないだように見えます。 |
| 手動 | 線の点が針落ち点になります。 |

**トリプル**は各ステッチを 3 回縫い(ビーンステッチ)、太い線にします。線のアウトラインの種類には次のものもあります:

- **モチーフラン**: 線に沿ってモチーフを繰り返します。**モチーフの長さ**、**モチーフの高さ**、**隙間**を設定します。
- **リップル**: 点の周りで小さくなる、またはガイド線に沿って動く、線のコピーです。**線**の数、**最後の線の大きさ**、**点**を設定します。ガイドを追加するには、線とガイド線を選択して、**編集 > ステッチの種類 > リップルのガイド**を使います。
- コラムの種類(下を見てください): 線を中心にした一定の幅のコラムとして縫います。

## コラム

| コラムの種類 | 縫い方 |
|---|---|
| サテン | 側から側へのなめらかなステッチ。縁と文字に。 |
| ジグザグ | 粗いサテン: 間をあけて側から側へ渡るステッチ。 |
| E ステッチ | ブランケットステッチ: 一方の側の線と、くしの歯のように横切るステッチ。 |
| 盛り上げサテン | ほかのサテンの層の上のサテンで、コラムが盛り上がります。幅 7 mm までが最適です。 |
| タタミ | コラムを横切る短いステッチの列。幅の広い縁に。 |
| スクエア | 側から側への四角い歯。粗い縁です。 |
| コイル | コラムを横切るループで、上から見たばねのようです。鋭い角は避けてください。 |
| 輪郭 | コラムの形に沿う、コラム方向の線。 |
| ストリング | ねじったひものように重なる斜めのステッチ。 |
| モチーフコラム | コラムに沿って繰り返すモチーフで、高さはコラムの幅と同じです。 |
| プログラム分割 | コラムに合わせて曲がる模様で針落ち点を置いたサテンの列。 |

## フィル

| フィルの種類 | 縫い方 |
|---|---|
| タタミ | 角度に沿ったまっすぐな列で、線が見えない模様です。 |
| サテン(とそのほかのコラムの種類) | 形を角度に沿って横切るコラムの種類。形を部分ごとに縫うので、外にステッチが出ません。 |
| スクエア | 針落ち点がそろったまっすぐな列: 均一なステッチの格子。 |
| ダブルスクエア | 交差する 2 層のスクエアのステッチで、織った格子のようです。 |
| 輪郭 | 形に沿って一方の端からもう一方へ続く線。 |
| オフセット | 縁の内側の輪で、縁から中心へ。 |
| スパイラル | 縁から中心へ回る 1 本の線。 |
| アイランドコイル | 縁から中心へのループの輪で、手作業のシェニールのようです。 |
| 放射状 | 中心の点から縁へ向かう線で、太陽の光線のようです。 |
| 迷路 | 中心へ回り、列の間を通ってまた外へ出る開いた線。 |
| フローレンタイン | ガイド線のように曲がる列。 |
| ストリング | 縁から縁へのまっすぐな線が曲線状に重なり、ストリングアートのようです。 |
| クロスステッチ | 手作業のクロスステッチのような、格子の上の十字。 |
| スティップル | 形を埋め、決して交差しない蛇行する線。 |
| モチーフフィル | モチーフの列。グラデーションで列ごとに大きさが変わり、球で列が曲がります。 |
| プログラム分割 | 絵になる模様で針落ち点を置いたタタミの列。 |
| フレキシ分割 | 形の辺に合わせて曲がるプログラム分割の模様。 |
| ユーザー分割 | 描いた線を横切る場所で分割される列。 |
| レイダウン | デザインの下の軽いフィルで、タオルや毛皮の毛足を押さえます。 |
| タータン | 織ったタータンの布のような、2 方向の色の縞。 |
| グラデーション | 形を横切って、ある色から次の色へ変わる列。 |
| メアンダー | タイルの模様(正方形、三角形、六角形)に沿った 1 本の線。 |
| 円形 | 中心の点の周りの輪で、スパイラルとして縫います。 |
| ガイド付き | 1 本以上のガイド線に沿い、線から線へと変わる列。 |
| レースのメッシュ | フリースタンディングレースの網: 2 方向の粗い列で、それぞれ往復して縫います。 |

一部のフィルの種類には、オブジェクトのプロパティにさらに設定があります: 分割の種類の**パターン**と**パターンのサイズ**、放射状と円形のフィルの**中央**、メアンダーの**タイル**、モチーフフィルの **3D ワープ（球）**、**彫刻スタンプ**(タタミに押し込む形: 列の線に沿って針落ち点が入ります)です。

## 線を使うフィル: ガイド線と分割線

- **ガイド線**(フローレンタイン): フィルと線を選択し、**編集 > ステッチの種類 > ガイド線**を使います。列が線のように曲がります。線は使われてなくなります。
- **ガイド線**(ガイド付き): フィルと 1 本以上の線を選択し、**ガイド線**を使います。列が線に沿い、線から線へと変わります。
- **分割線**(ユーザー分割): フィルと 1 本以上の線を選択し、**分割線**を使います。列が線を横切る場所で分割されるので、フィルに線が見えます。

オブジェクトのプロパティに、ガイド線か分割線の数と、それを削除するボタンが表示されます。

## タータン

1. フィルを選択し、**編集 > ステッチの種類 > タータン**を使います。
2. **セット**を入力します: 各縞の色コードと糸の本数です。たとえば `K4 R24 K24 Y4`(K 黒、R 赤、Y 黄)。**セット…**に始めるためのセットがいくつかあります。ウィンドウにすべての色コードが一覧されます。
3. **対称**: ほとんどのタータンのように、縞が最後の縞まで進んで戻ります。
4. **1 本あたりの幅**で縞の大きさを設定します。
5. **タータンを作る**をクリックします。

プログラムは色ごとに 1 つのフィルを、1 つのグループで作ります。タータンでは、同じ色の縞の間に糸切りがあるので、糸がほかの色の上を通りません。

## グラデーション

1. フィルを選択し、**編集 > ステッチの種類 > グラデーション**を使います。
2. 色を追加します。各色に糸と、0 %(形の一方の側)から 100 %(もう一方の側)までの位置を付けます。
3. **グラデーションを作る**をクリックします。

フィルの角度で列の方向が決まります。各列は 1 色なので、密度は同じままです。1 色だけのグラデーションは生地へと薄れていきます。

## モチーフ

**編集 > ステッチの種類 > モチーフ**でモチーフのライブラリを開きます:

- **選択範囲に使う**: 線はモチーフラン、サテンコラムはモチーフコラム、フィルはモチーフフィルになります。
- **選択範囲から作成**: 選択したオブジェクトのステッチがモチーフになります。その矩形の左右の中央が基準点です。
- **名前の変更**と**削除**で自分のモチーフを変えます。デザインはモチーフのコピーを保持します。

## ブレンド

**デジタイズ > ブレンド**は、1 つのフィルかサテンコラムに 2 色以上を混ぜます: 一方の側からもう一方へ密度が変わる層です。**2 つ目の色**を設定し、**カラーブレンドを作成**をクリックします。さらに層を追加し、各層の密度を始めから終わりまで設定します。

## 縁取り

**デジタイズ > 縁取り**は、選択範囲の周り(何も選択していなければデザイン全体の周り)に装飾の縁(サテン、ラン、ブランケット、ロープ、モチーフ)を追加します。**オブジェクトの周りの間隔**を設定し、**縁取りを追加**をクリックします。

## ボタンホール

**デジタイズ > ボタンホール**は、7 つの形と標準サイズのボタンホールとアイレットを作ります: 1 つ、または選択した線に沿った列です。[ボタンホールとアイレット](buttonholes)を見てください。
