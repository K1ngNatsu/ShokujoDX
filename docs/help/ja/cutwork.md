# カットワーク

カットワークキット(刃の付いた 4 本の針)のあるミシンは、デザインの内側の生地を切ります。たとえばリシュリュー刺しゅうやアイレットのためです。**特殊 > カットワーク**で、選択した線を切り線にします。

## 切り線を作る

1. 生地を切る場所に線を描きます(デジタイズ > 線)。
2. 線を選択し、**特殊 > カットワーク**をクリックします。
3. **キット**を選びます: Bernina、Brother と Baby Lock、Husqvarna Viking と Pfaff、Janome。プログラムは、できればデザインのミシンのブランドを使います。
4. **切る間隔**を設定します: 線に沿った、針の 2 回の切り込みの間の距離です。
5. **切り線を作る**をクリックします。

## 切り線の縫い方

- 各刃は 1 つの方向に切ります(水平、`/`、垂直、`\`)。線の各部分は、その方向の刃を持つ針に割り当てられます。
- 各針は 1 つの色で、たとえば「Cutwork needle 2 (/)」という名前です。ミシンは針を替えるために止まります。
- 切り線には止め縫いがなく、部分の間で針が上がります。

## カットワークのデザイン

1. 生地が動かないように、先に各切り込みの周りにランニングの線を縫います。
2. 切り線を縫います。
3. そのあと、切った縁の上にサテンの縁取りを縫います。
4. 切ったピースを生地に残す場所では、切り線に小さな隙間を残します。

各ミシンがファイルの中でカット針をどう見分けるかは公開されておらず、ファイルはまだミシンで試されていません。先に端切れで試してください。
