# デザインライブラリーとクリップアート

## デザインライブラリー

**デザイン > デザインライブラリー**(または**ファイル > デザインライブラリー**)で、ライブラリーパネルを表示します: デザインフォルダーとそのサブフォルダーのデザインが、それぞれの画像とともに表示されます。

- **ライブラリーフォルダーを追加**でフォルダーを追加します。**削除**でライブラリーから外します(ファイルは削除されません)。**再スキャン**で、新しいデザインと変更されたデザインを読みます。
- **サムネイル**か**一覧**でデザインを表示します。一覧では、列の見出し(名前、形式、サイズ、ステッチ、色、フォルダー)をクリックしてその順に並べます。もう一度クリックすると逆の順になります。
- **検索**で、名前、ファイル、フォルダー、メモ、糸、形式の言葉からデザインを探します。フィルターで検索を絞り込みます:

| フィルター | 探すもの |
|---|---|
| `format:vp3,dst` | これらの形式のデザイン |
| `folder:caps` | この名前のフォルダーのデザイン |
| `colors:<4` | 色が 4 色未満のデザイン |
| `stitches:1000-5000` | ステッチが 1000 から 5000 のデザイン |
| `width:<100`, `height:>50` | mm で指定したサイズのデザイン |
| `fits:crown` | 枠に入るデザイン |
| `error:yes` | 読めないデザイン |
| `"two words"` | 2 つの言葉が並んだもの |

デザインを選択しているとき:

- **開く**(またはダブルクリック)で開きます。
- **選択から新規**で、選択したデザインのコピーである新しいデザインを作ります。ファイルは変わりません。
- **エクスプローラーで表示**でファイルを表示します。
- **選択を出力**で、選択した各デザインについて、出力プロファイルのファイル(ミシンファイル、作業シート、画像)を 1 つのフォルダーに作ります。
- **USB へ送信**で、選択したデザインを、開いているデザインのミシンの USB スティックへ、その形式で送ります。

見つかったデザインを印刷または一覧にするには:

- **カタログ（PDF）**: 各デザインの画像と数値を、1 ページに 20 個。
- **デザイン一覧（CSV）**: 表計算ソフト用の、デザインとその数値。

## クリップアート

クリップアートの項目は、何度も使うデザインの部品です: フレーム、バッジ、小さな絵などです。プログラムにはいくつかの項目があり、自分の項目も追加できます。

- **編集 > クリップアート**で、クリップアートパネルを表示します。**クリップアートを検索**で、名前やキーワードから項目を探します。
- 項目をダブルクリックするか、デザインの上にドラッグして挿入します。**挿入**も同じです。
- **編集 > クリップアートとして保存**で、選択したオブジェクトを項目として、**名前**と**キーワード**(検索で見つかる言葉。たとえば「バラ 花 赤」)とともに保ちます。
- **クリップアートフォルダーを表示**でフォルダーを開きます。**クリップアートフォルダーを再読み込み**で、そこの新しいファイルを見つけます。

クリップアートは自分のアセットの 1 つです: **マイアセット**でエクスポートと読み込みをします。[生地、スタイル、テンプレート](fabrics-and-styles)を見てください。
