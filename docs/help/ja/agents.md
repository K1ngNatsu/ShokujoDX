# エージェント (MCP)

自分の AI エージェント (ツールを使えるアシスタントのプログラム) で、ShokujoDX のデザインを作ったり変えたりできます。プログラムには AI がなく、ネットワークも使いません。エージェントはプログラムのコマンドラインツール `emb-cli` を起動し、`emb-cli mcp` が Model Context Protocol (MCP) でプログラムのツールをエージェントに渡します。

## 設定

エージェントの MCP 設定に、次のコマンドでサーバーを追加します (ShokujoDX のフォルダー、その後に `emb-cli mcp`)。

```text
"C:\Program Files\ShokujoDX\emb-cli.exe" mcp
```

Mac では、ツールはプログラムの中にあります: `ShokujoDX.app/Contents/MacOS/emb-cli`。Linux では `emb-cli` が `shokujodx` の隣にあります。多くのエージェントは、サーバーを JSON ファイルに書きます。

```json
{
  "mcpServers": {
    "shokujodx": {
      "command": "C:\\Program Files\\ShokujoDX\\emb-cli.exe",
      "args": ["mcp"]
    }
  }
}
```

## エージェントができること

サーバーはデザインを 1 つ持ちます。そのツール:

- 新しいデザインを始める、またはデザイン (プロジェクト、ミシンファイル、SVG ファイル) を開き、保存する。
- オブジェクトの一覧を出し、SVG のパスのテキストから形 (線、フィル、サテン列、ベクターの形) を追加し、プログラムの刺繍フォントで文字を追加する。
- オブジェクトの設定と糸を変え、移動、拡大縮小、回転、削除をし、スクリプトを実行する ([スクリプト](scripts)を参照)。
- デザインを確認し、3D の糸の見た目で画像を作り、ミシンファイル、作業シート、承認シートを書き出す。
- 試し縫いを作り、デザインを速く縫えるようにし、ミシンファイルを確認して修正する。
- 元に戻す、やり直す。

変更は 1 つずつ元に戻す手順になります。寸法は、枠の中央からの mm です。読むだけのツールはそう示し、ツールは知らない引数を受け付けません。

## プログラムでデザインを見る

ツール **show** はデザインを保存して ShokujoDX で開きます。起動中のプログラムの新しいタブで開き、プログラムが起動していなければ新しいプログラムで開きます。

タブで開いているファイルをエージェントが保存すると、プログラムが確認します。**もう一度開く** で新しい版を表示します (タブの保存していない変更はなくなります)。**この版を残す** でタブをそのままにします。

## 試す

エージェントに 1 文でデザインを頼みます。例:「幅 60 mm の丸いワッペンを作り、赤で STAR と入れ、青いサテンの縁を付けて、ShokujoDX で見せて」。
