# ボタンホールとアイレット

刺しゅうミシンは、デザインと一緒にボタンホールとアイレットを縫えるので、ミシンを替える必要がありません。**デジタイズ > ボタンホール**で、ボタンホールウィンドウを開きます。

## 形

| 形 | 用途 |
|---|---|
| 角型 | 普通のボタンホール: シャツ、ブラウス、ほとんどの織物。 |
| 片丸 | ボタンの足のための丸い端: ブラウス、ワンピース、ズボン。 |
| 両丸 | やわらかい丸い両端: 薄手、繊細、透ける生地。 |
| 鳩目穴 | 足付きの厚いボタン用の鳩目: コート、ジャケット、厚手の生地。 |
| 先細の鳩目穴 | 先がとがった鳩目穴: テーラードのジャケットやコート。 |
| ストレッチ（ニット用） | 生地と一緒に伸びる、粗いジグザグの脚: ニットやジャージー。 |
| アイレット | コード、ひも、ベルト、引きひも用の丸い穴。 |

各ボタンホールは、最初にランニングの囲み(生地を押さえます)を縫い、次に切り込み用の隙間をはさんだサテンの脚、最後に端を縫います。ウィンドウの画像に形が表示されます。

## サイズ

- **ボタン** > **標準サイズ**: ボタンの直径を、インチまたは mm で選びます。ボタンメーカーの単位であるリーニュ (L) のサイズは、かっこ内です: 20L は 1/2 in です。
- **ボタンの厚さ**: 普通の平らなボタンは 2 mm です。ドーム形のボタンや足付きボタンには、より大きい値が必要です。
- **開口**: 切り込みの長さで、ボタンの直径と厚さです。自分で設定するには長さを入力します。たとえば `5/8 in`。
- アイレットでは、**穴**が穴の直径です。
- **サイズに合わせてステッチを拡大縮小**: 脚、隙間、かんぬき止め、鳩目がサイズに合わせて変わるので、小さいボタンホールは細く、大きいものは太くなります。自分の設定を保つにはオフにします。
- **ステッチ**: **脚の幅**、**切り込みの隙間**、**かんぬき止め**、鳩目穴の**鳩目**、**密度**。
- **芯糸入り**: 各脚の下にランニングを入れ、芯糸のようにします。ボタンホールが丈夫になり、より立ち上がります。
- **マイターの角**(角型、片丸、鳩目穴): 脚とかんぬき止めを、角で曲がる 1 つのコラムとして、止まらずに縫います。かんぬき止めのほうが切り込みの端をしっかり押さえます: マイターの角は薄い生地と飾りに使います。
- **端を反対にする**: 丸い端、鳩目、またはとがった端が反対の端になります。ボタンの足の側に置きます: 水平のボタンホールでは衣類の端の近くです。

## ボタンホールを配置する

- 線を選択していない場合、**ボタンホールを 1 つ配置**で、枠の中央に 1 つ置きます。**垂直**か**水平**です。
- ボタンホールを置く場所に線を描き(デジタイズ > 線)、選択してから、**ボタンホールを配置**をクリックします。線は使われてなくなります。ボタンホールの間隔は、**数**(最初と最後を線の両端に置く)か、**間隔**(線の始点から)で決めます。**線を横切る**で、線を横切る向きにします。たとえばコートです。オフでは線に沿います。たとえばシャツの前立てです。

1 回のクリックのボタンホールは 1 つのグループです。枠より大きい列は枠入れで縫います: [枠より大きいデザイン](hooping)を見てください。

## ボタンホールを変更する

配置したボタンホールを選択し、**デジタイズ > ボタンホール**をクリックします: ウィンドウにその設定が表示されます。設定を変えて、**選択したボタンホールを変更**をクリックします。各ボタンホールは、動かしたり、回したり、反転したりしたあとでも、その位置で作り直されます。元に戻すで、変更を 1 回で取り消します。囲みを削除したボタンホールは作り直されません。

## 縫って切る

1. 裏打ちを付けて生地を枠に張ります。薄い生地では、ボタンホールの下に接着芯を貼ります。ニットでは、カットタイプの裏打ちと**ストレッチ（ニット用）**の形を使います。
2. デザインを縫います。ミシンはボタンホールをほかのオブジェクトと同じように縫います。
3. 各端にまち針を横に刺してから、リッパーかボタンホールカッターで脚の間の開口を切ります。アイレットの穴と鳩目穴の鳩目は、切るか穴をあけます。
4. まず同じ生地の端切れでサイズを試してください: ボタンが開口を楽に通る必要があります。
