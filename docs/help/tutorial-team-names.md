# Tutorial: team names

In this tutorial you make one design for a team: the name and the number
change for each player. You paste a list of names, look at one name in
the design, and put all names in one design.

## Open the start design

Click [Open the start design](sample:team-shirt). It has the back of a
team shirt: **NAME** in navy (Block Sans, 12 mm) and **00** in red
(Varsity, 25 mm). The team names use these two lettering objects as
their columns: the font, the size and the color stay, the text changes.

## Make the columns

1. Drag a box round **NAME** to select it.
2. Click **Lettering > Personalize > Team Names**. The **Team Names**
   window opens, with the selected lettering as the column **Name**.
3. Drag a box round **00** to select it.
4. Click **Add the selected lettering as a column**. The second column is
   **Player number**. Click a title to change it.

**Fit to width** makes a long name smaller, so that it is not wider than
the value (for example the width between the seams of a sleeve).

## Add the names

1. Click **Paste a list**.
2. Click the field under it, and type the names, one name on each line,
   with the number after a semicolon:

   ```text
   Anna;7
   Ben;10
   Carla;23
   David;4
   ```

3. Click **Add these names**. The list has four rows.

![The Team Names window with four names](team-names-window)

A list from a spreadsheet can have commas, semicolons or tabs between the
columns: **Import CSV…** reads a file. **Qty** is the number of shirts
with that name.

## Look at one name

Click **Show** on the row of Anna. The design shows **Anna** and **7** in
the fonts and colors of the columns.

![The design with the name of Anna](team-names-anna)

Look at the longest name: it must not be too wide for the shirt.

## Write the files

- **Save each name…** writes one machine file for each name in a folder
  that you choose, in one step. The name of each file is the name of the
  player.
- **All in one design** puts all names in one design (a new tab), color
  by color, to sew them on a sheet of fabric for patches in one hooping.

Click **All in one design**. The new tab has the four names and their
numbers: eight objects in two colors. The names stay inside the safety
margin of the hoop, so they go in two rows.

![All names in one design](team-names-all)

## If it does not look right

- **A name is missing.** The list has an empty row, or the line has no
  name. Look at the rows of the list.
- **A name is too wide.** Click **Fit to width** for the column, and set
  the width.
- **All in one design does not fit the hoop.** Use fewer names, or a
  larger hoop.
