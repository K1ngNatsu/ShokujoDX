# Specialty decoration

The **Specialty** tab has the kinds of decoration that need more than
normal stitches:

- **Cross Stitch**: crosses on a grid, and a chart for hand cross stitch.
  See [Cross stitch](cross-stitch).
- **Rhinestones**: stones that you press on with heat, and the template
  to put them in place. See [Rhinestones](rhinestones).
- **Cutwork**: cut lines for the cutting needles of a cutwork kit. See
  [Cutwork](cutwork).
- **Quilting**: echo lines, background stipples and quilt blocks. See
  [Quilting](quilting).
- **Puff** and **Laydown**: below.

Free-standing lace is a fabric setting and a fill type; it is below too.

## Puff (3D foam)

Puff letters and columns sew over foam, so they stand up from the fabric.
Select satin columns or lettering, then click **Specialty > Puff** (or
the **Puff (3D foam)** box in Object Properties). Click again to turn it
off.

- The satin is dense, and the underlay has no rows across the column,
  because they would press the foam flat.
- Stitches go over each end of a column, so the needle cuts the foam
  there and the end is closed.
- The machine stops before the first puff object, so you can put the
  foam on; the worksheet says so. Tear the foam away after the puff
  objects.
- Use columns 3 mm wide or more, and foam of a color like the thread.

## Laydown

On towels, fleece and fur, the pile pushes up through the stitches.
**Specialty > Laydown** adds a light fill under the selected objects (or
the whole design): it holds down the pile. It sews first, in a thread of
its own. Use a thread of the fabric color, so the laydown does not show.

With the fabric **Towel (terry)** (Design > Fabric), use a topping too.
See [Tutorial: a monogram on a towel](tutorial-towel).

## Free-standing lace

Free-standing lace has no fabric. You sew it on water-soluble
stabilizer, then wash the stabilizer away. The lace must hold together:

- Start from **Design > New from Template > Lace ornament** or **Lace
  edge**, or set the fabric **Water-soluble stabilizer (free-standing
  lace)** in **Design > Fabric**.
- Put a **Lace mesh** fill under the design (Object Properties > Fill
  type). The mesh is a net of rows in two directions; each row goes
  there and back, so the threads lock where they cross.
- Give satin columns and fills the **Lace** underlay: a run along the
  edge two times, then a zigzag or rows across it. The water-soluble
  fabric sets it on the objects with automatic underlay.
- Each part must touch the mesh or another part. **Design Info** lists
  each loose part (thread that touches no other part); click it to
  select the part.
- Hoop two layers of stabilizer tight, and use the same thread in the
  needle and the bobbin, because both sides show.

See [Tutorial: a lace ornament](tutorial-lace).
