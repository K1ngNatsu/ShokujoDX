# Glossary

| Word | Meaning |
|---|---|
| Appliqué | A piece of fabric sewn onto the design: a placement line, a tack-down and a cover satin. |
| Backing | A stabilizer under the fabric. Cut-away for knits, tear-away for woven fabric. |
| Bean stitch | A running stitch with each stitch sewn three times (Triple), for a heavier line. |
| Bobbin | The thread under the fabric. It locks with the top thread at each needle point. |
| Border trace | A border or a gap round objects, cut out of the objects under them. |
| Color change | The machine stops, or goes to another needle, to sew another thread. |
| Colorway | One set of colors of a design. A design can have more colorways. |
| Column | A satin column: stitches across a shape from one side (rail A) to the other (rail B). |
| Current properties | The stitch settings that new objects get. |
| Density | The distance between rows or satin stitches. Smaller is denser. |
| Density map | A view that colors the design by the layers of thread. |
| Digitize | To make an embroidery design: shapes, stitch types, sew order and settings. |
| Fill | Rows of stitches that cover an area. |
| Hoop | The frame that holds the fabric on the machine. The field is where the needle can go. |
| Hooping | One part of a design that is larger than the hoop. |
| Jump | A move of the hoop with no stitch. |
| Laydown | A light fill under the design that holds down the pile of towels and fleece. |
| Lock stitch | Small stitches that hold the thread at the start or end of an object (tie-in, tie-off). |
| Machine file | The needle points and functions of a design for one machine (DST, PES, VP3 and others). |
| Motif | A small stitch pattern that repeats along a line, a column or in a fill. |
| Needle point | A place where the needle goes through the fabric. |
| Object | One part of a design: a line, a column, a fill, an appliqué, lettering and more. |
| Project | The file of this program (.embproj), with all objects and settings. |
| Pull compensation | Extra width, because the stitches pull the fabric in across their direction. |
| Registration marks | Crosses that align two hoopings, or a rhinestone template. |
| Running stitch | Stitches one after the other along a line. |
| Satin | Smooth stitches from side to side of a column. They shine. |
| Sett | The stripes of one repeat of a tartan, for example K4 R24 K24 Y4. |
| Sew order | The order in which the objects sew. An object that sews later lies on top. |
| Split | Extra needle points in long stitches, so they do not snag. |
| Stabilizer | Material that holds the fabric while it is sewn: backing and topping. |
| Stitch | The thread between two needle points. |
| Stitch cursor | A mark on one stitch, to check the design stitch by stitch. |
| Stitch object | Stitches from a machine file or a photo stitch, sewn as they are. |
| Stop | The machine stops, so you can do something by hand. |
| Style | A set of stitch settings with a name. |
| Tack-down | Stitches that hold appliqué fabric before the cover satin. |
| Tatami | A fill of straight rows in a pattern that does not show lines. |
| Thread chart | The list of colors of a thread brand. |
| Topping | A water-soluble film on top of towels, fleece and velvet. |
| Travel | Stitches that go from one part to the next, under stitches that cover them. |
| Trim | The machine cuts the thread. |
| Underlay | Stitches under the top stitches that hold the fabric and lift the top stitches. |
| Vector | A shape with no stitches. Convert makes embroidery from it. |
