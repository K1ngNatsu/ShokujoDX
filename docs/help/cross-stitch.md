# Cross stitch

Cross-stitch objects have crosses in the cells of a grid, as in hand
cross stitch. The crosses of all objects on one grid line up.

## Draw crosses

- **Specialty > Cross Stitch**: click or drag over the cells of the grid
  to put crosses in them, in the current color. **Shift+drag** erases.
- The property bar sets the kind of cross: **Full cross**, **Half cross
  /**, **Half cross \**, **Quarter cross** or **Three-quarter cross**.
  Quarter and three-quarter crosses go to the corner of the cell nearest
  to the pointer.
- The property bar sets the **Cell size**, in mm or as an Aida count
  (for example Aida 14). A new cell size starts a new grid. To draw on
  the grid of an object, select it first; to use the cell size of the
  property bar, click an empty place first.
- **Erase Cells** removes crosses and backstitch lines: click or drag
  over them.
- **Backstitch** draws lines along the cell sides and diagonals: click
  cell corners or cell centers. A right click or **Esc** ends the line.

## Make cross stitch from other objects

- **To Cross Stitch** changes the selected fills, appliqué, satin
  columns and closed vectors into cross stitch: a full cross in each cell
  whose center is inside the shape.
- **Picture to Cross Stitch** makes cross stitch from a picture: choose
  it, remove the background, then set the cell size and the number of
  thread colors. See [Pictures and Picture to design](pictures).

## Settings of a cross-stitch object

Select the object. Object Properties shows the number of crosses of each
kind, the size in cells, and:

- **Cell size**: all cross-stitch objects on this grid change.
- **Each leg**: **Once**, or **3 times** for a heavier cross (thin thread,
  a textured fabric).
- **Order**: **Rows** (all top legs go the same way; travel stitches go
  along the cell sides) or **Zigzag** (no travel stitches, but the top leg
  changes from cell to cell).
- **Backstitch**: once or 3 times.

## The chart

**Specialty > Chart** writes the chart as PDF, for hand cross stitch:

- a symbol for each color in each cell;
- the key with the threads and the number of stitches;
- the size on Aida 11, 14, 16 and 18 fabric.

A large chart goes on more pages.
