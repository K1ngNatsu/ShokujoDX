# Tutorial: Japanese text

In this tutorial you make lettering with Japanese characters (kana and
kanji) in a font of your computer, and find the smallest height at
which the characters sew well. Chinese and Korean text works the same
way.

## A font with Japanese characters

The font must have the characters of your text. Most computers have one:

- Windows: **Yu Gothic** or **Meiryo**.
- macOS: **Hiragino Sans**.
- Linux: **Noto Sans CJK JP**.

**Noto Sans JP** is a free font that you can add to any computer. A bold
font sews better than a thin one: its strokes are wide enough for satin
columns.

The font packages of the program have Japanese embroidery fonts (**More
Fonts…** in **Lettering > Lettering > Fonts**).

## Make the lettering

1. Click [Open the start design](sample:lettering-start).
2. Click **Lettering > Lettering > Lettering**, and click the
   construction point.
3. Type the text with the input method of your computer, for example
   `さくら` (sakura, cherry blossom).
4. In the **Font** list, select a font with Japanese characters, for
   example **Noto Sans JP**.
5. Set **Height** to 15 mm. For text with Japanese, Chinese or Korean
   characters, the height is the height of these characters, not of the
   capital letters.

The window says the height from which the characters of this text sew
well. Kanji with many strokes need more height than kana.

![The Lettering window with Japanese text](japanese-window)

6. Click **OK**.

## Look at the stitches

Click **View > Show > Thread Look**, and select **Thread Look** in its
menu.

![さくら in satin columns](japanese-stitches)

Each stroke of a character is a satin column, and a narrow stroke is a
running stitch.

## Text that is too small

Set **Height** in Object Properties to 5 mm. The size range shows in
the color of a warning, and Design Info has a warning: the text is
smaller than the size range. Make the text larger, or use fewer strokes
(kana in place of kanji).

## If it does not look right

- **The characters are empty boxes, or are missing.** The font does not
  have them. The window says which characters are missing. Select a font
  with Japanese characters.
- **Strokes run into each other.** The text is too small: make it larger
  than the height that the window says.
- **The text is very thin.** Use a bold font.
