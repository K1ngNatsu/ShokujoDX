# Glosario

| Palabra | Significado |
|---|---|
| Aplique | Una pieza de tela bordada sobre el diseño: una línea de colocación, una fijación y un satén de cubierta. |
| Archivo de máquina | Las penetraciones de aguja y las funciones de un diseño para una máquina (DST, PES, VP3 y otros). |
| Base | Puntadas debajo de las puntadas superiores que sujetan la tela y levantan las puntadas superiores. |
| Bastidor | El marco que sujeta la tela en la máquina. El campo es adonde puede ir la aguja. |
| Bobina | El hilo debajo de la tela. Se traba con el hilo superior en cada penetración de la aguja. |
| Cambio de color | La máquina se detiene, o va a otra aguja, para bordar otro hilo. |
| Capa base | Un relleno ligero debajo del diseño que sujeta el pelo de toallas y forro polar. |
| Carta de hilos | La lista de colores de una marca de hilo. |
| Colocación en bastidor | Una parte de un diseño más grande que el bastidor. |
| Columna | Una columna de satén: puntadas a través de una forma de un lado (riel A) al otro (riel B). |
| Combinación de colores | Un conjunto de colores de un diseño. Un diseño puede tener más combinaciones. |
| Compensación de tiro | Ancho extra, porque las puntadas encogen la tela en sentido transversal a su dirección. |
| Corte | La máquina corta el hilo. |
| Cursor de puntada | Una marca en una puntada, para comprobar el diseño puntada a puntada. |
| Densidad | La distancia entre filas o puntadas de satén. Más pequeña es más densa. |
| Desplazamiento | Puntadas que van de una parte a la siguiente, debajo de puntadas que las cubren. |
| Digitalizar | Hacer un diseño de bordado: formas, tipos de puntada, orden de bordado y ajustes. |
| Dividir | Penetraciones de aguja extra en puntadas largas, para que no se enganchen. |
| Entretela | Un estabilizador debajo de la tela. De cortar para tejidos de punto, de arrancar para tejidos planos. |
| Estabilizador | Material que sujeta la tela mientras se borda: entretela y recubrimiento. |
| Estilo | Un conjunto de ajustes de puntada con un nombre. |
| Fijación | Puntadas que sujetan la tela del aplique antes del satén de cubierta. |
| Mapa de densidad | Una vista que colorea el diseño según las capas de hilo. |
| Marcas de registro | Cruces que alinean dos colocaciones, o una plantilla de strass. |
| Motivo | Un pequeño patrón de puntadas que se repite a lo largo de una línea, una columna o en un relleno. |
| Objeto | Una parte de un diseño: una línea, una columna, un relleno, un aplique, letras y más. |
| Objeto de puntadas | Puntadas de un archivo de máquina o de una puntada fotográfica, bordadas tal como son. |
| Orden de bordado | El orden en que se bordan los objetos. Un objeto que se borda después queda encima. |
| Parada | La máquina se detiene, para que pueda hacer algo a mano. |
| Penetración de aguja | Un lugar donde la aguja atraviesa la tela. |
| Propiedades actuales | Los ajustes de puntada que reciben los objetos nuevos. |
| Proyecto | El archivo de este programa (.embproj), con todos los objetos y ajustes. |
| Puntada | El hilo entre dos penetraciones de aguja. |
| Puntada de frijol | Una puntada recta con cada puntada bordada tres veces (Triple), para una línea más gruesa. |
| Puntada de remate | Puntadas pequeñas que sujetan el hilo al inicio o al final de un objeto. |
| Puntada recta | Puntadas una tras otra a lo largo de una línea. |
| Recubrimiento | Una película hidrosoluble encima de toallas, forro polar y terciopelo. |
| Relleno | Filas de puntadas que cubren un área. |
| Salto | Un movimiento del bastidor sin puntada. |
| Satén | Puntadas lisas de un lado a otro de una columna. Brillan. |
| Sett | Las rayas de una repetición de un tartán, por ejemplo K4 R24 K24 Y4. |
| Tatami | Un relleno de filas rectas en un patrón que no muestra líneas. |
| Trazado de borde | Un borde o un hueco alrededor de objetos, recortado de los objetos que hay debajo. |
| Vector | Una forma sin puntadas. Convertir hace bordado a partir de ella. |
