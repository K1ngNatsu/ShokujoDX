# Sticharten

Die Stichart legt das Muster der Stiche eines Objekts fest. Legen Sie sie
in den Objekteigenschaften fest, oder für viele Objekte auf einmal mit
**Bearbeiten > Sticharten**:

- **Umrissart**: Die ausgewählten Linien werden als einfache Linie
  gestickt, oder als Säule einer Stichart entlang der Linie (mit einer
  Breite).
- **Füllart**: die Stichart der ausgewählten Füllungen.
- **Säulenart**: die Stichart der ausgewählten Satinsäulen und der Linien
  mit einer Breite.

Jede Änderung ist ein Schritt zum Rückgängigmachen. Halten Sie den Zeiger
auf eine Art in der Liste, um zu sehen, was sie tut.

## Linien

Die Steppstichart (Eigenschaftsleiste und Objekteigenschaften):

| Steppstichart | Was sie stickt |
|---|---|
| Steppstich | Gleichmäßige Stiche entlang der Linie. |
| Rückstich | Zwei halbe Schritte vor, einen zurück, wie ein Rückstich von Hand. |
| Stielstich | Ein Rückstich mit den Vorwärtsstichen etwas zur Seite, wie ein Stielstich von Hand. |
| Skulpturstich | Dreifache und einfache Stiche im Wechsel, damit die Linie wie eine Perlenschnur aussieht. |
| Manuell | Die Punkte der Linie sind die Einstichpunkte. |

**Dreifach** stickt jeden Stich dreimal (ein Bohnenstich), für eine
kräftigere Linie. Die Umrissarten einer Linie sind außerdem:

- **Motivlinie**: ein Motiv, das sich entlang der Linie wiederholt. Legen
  Sie **Motivlänge**, **Motivhöhe** und **Lücke** fest.
- **Welle**: Kopien der Linie, die um einen Punkt kleiner werden oder
  sich entlang einer Führungslinie bewegen. Legen Sie die Zahl der
  **Linien**, die **Größe der letzten Linie** und den **Punkt** fest. Um
  eine Führung hinzuzufügen, wählen Sie die Linie und eine Führungslinie
  aus, dann **Bearbeiten > Sticharten > Wellenführung**.
- Eine Säulenart (siehe unten): Die Linie wird als Säule fester Breite
  gestickt, mit der Linie als Mitte.

## Säulen

| Säulenart | Was sie stickt |
|---|---|
| Satin | Glatte Stiche von Seite zu Seite. Für Ränder und Schrift. |
| Zickzack | Offener Satin: Stiche von Seite zu Seite mit Abstand dazwischen. |
| E-Stich | Langettenstich: eine Linie auf einer Seite, mit Stichen quer wie die Zähne eines Kamms. |
| Erhabener Satin | Satin über weiteren Satinlagen, damit die Säule hervorsteht. Am besten bis 7 mm Breite. |
| Tatami | Reihen kurzer Stiche quer über die Säule, für breite Ränder. |
| Quadrat | Eckige Zähne von Seite zu Seite, ein offener Rand. |
| Spirale | Schlaufen quer über die Säule, wie eine Feder von oben gesehen. Vermeiden Sie scharfe Ecken. |
| Kontur | Linien entlang der Säule, die ihrer Form folgen. |
| Kordel | Schräge Stiche, die sich wie eine gedrehte Kordel überlappen. |
| Motivsäule | Ein Motiv, das sich entlang der Säule wiederholt, so hoch wie die Säule breit ist. |
| Programmsplit | Satinreihen mit den Einstichpunkten in einem Muster, das sich mit der Säule biegt. |

## Füllungen

| Füllart | Was sie stickt |
|---|---|
| Tatami | Gerade Reihen im Winkel, in einem Muster, das keine Linien zeigt. |
| Satin (und andere Säulenarten) | Die Säulenart quer über die Form im Winkel. Die Form wird in Teilen gestickt, darum geht kein Stich nach außen. |
| Quadrat | Gerade Reihen mit den Einstichpunkten in einer Linie: ein Raster gleichmäßiger Stiche. |
| Doppelquadrat | Zwei Lagen Quadratstiche, die sich kreuzen, wie ein gewebtes Raster. |
| Kontur | Linien, die der Form von einem Ende zum anderen folgen. |
| Versatz | Ringe innerhalb der Kante, von der Kante bis zur Mitte. |
| Spirale | Eine Linie, die sich von der Kante zur Mitte dreht. |
| Inselspirale | Ringe aus Schlaufen von der Kante zur Mitte, wie Chenille von Hand. |
| Radial | Linien von einem Mittelpunkt hinaus zur Kante, wie Sonnenstrahlen. |
| Labyrinth | Eine offene Linie, die zur Mitte herumgeht und zwischen ihren Reihen wieder hinaus. |
| Florentiner | Reihen, die sich wie eine Führungslinie biegen. |
| Kordel | Gerade Linien von Kante zu Kante, die sich in Kurven überlappen, wie Fadengrafik. |
| Kreuzstich | Kreuze auf einem Raster, wie beim Kreuzstich von Hand. |
| Stippling | Eine mäandernde Linie, die die Form füllt und sich nie kreuzt. |
| Motivfüllung | Reihen eines Motivs. Ein Verlauf ändert die Größe von Reihe zu Reihe; die Kugel biegt die Reihen. |
| Programmsplit | Tatamireihen mit den Einstichpunkten in einem Muster, das ein Bild ergibt. |
| Flexi-Split | Ein Programmsplit-Muster, das sich mit den Seiten der Form biegt. |
| Eigene Teilung | Reihen, die dort geteilt werden, wo sie von Ihnen gezeichnete Linien kreuzen. |
| Grundlage | Eine leichte Füllung unter dem Design, die den Flor von Handtüchern und Fell niederhält. |
| Tartan | Farbstreifen in zwei Richtungen, wie auf gewebtem Tartanstoff. |
| Verlauf | Reihen, die über die Form von einer Farbe zur nächsten wechseln. |
| Mäander | Eine Linie entlang eines Kachelmusters (Quadrate, Dreiecke oder Sechsecke). |
| Kreisförmig | Ringe um einen Mittelpunkt, als Spirale gestickt. |
| Geführt | Reihen, die einer oder mehreren Führungslinien folgen und von einer zur nächsten wechseln. |
| Spitzennetz | Das Netz freistehender Spitze: offene Reihen in zwei Richtungen, jede hin und zurück gestickt. |

Manche Füllarten haben weitere Einstellungen in den Objekteigenschaften:
das **Muster** und die **Mustergröße** der Split-Arten, die **Mitte**
radialer und kreisförmiger Füllungen, die **Kacheln** eines Mäanders, die
**3D-Verzerrung (Kugel)** einer Motivfüllung und die **Prägestempel**
(Formen, die in ein Tatami gedrückt werden: Die Reihen bekommen
Einstichpunkte entlang ihrer Linien).

## Füllungen mit Linien: Führungslinien und Teilungslinien

- **Führungslinie** (Florentiner): Wählen Sie eine Füllung und eine Linie
  aus, dann **Bearbeiten > Sticharten > Führungslinie**. Die Reihen biegen
  sich wie die Linie. Die Linie wird verbraucht.
- **Führungslinien** (Geführt): Wählen Sie eine Füllung und eine oder
  mehrere Linien aus, dann **Führungslinien**. Die Reihen folgen den
  Linien und wechseln von einer zur nächsten.
- **Teilungslinien** (Eigene Teilung): Wählen Sie eine Füllung und eine
  oder mehrere Linien aus, dann **Teilungslinien**. Die Reihen werden dort
  geteilt, wo sie die Linien kreuzen, darum zeigen sich die Linien in der
  Füllung.

Die Objekteigenschaften zeigen die Zahl der Führungs- oder Teilungslinien,
mit einer Schaltfläche, um sie zu entfernen.

## Tartan

1. Wählen Sie eine Füllung aus, dann **Bearbeiten > Sticharten > Tartan**.
2. Tippen Sie das **Sett**: einen Farbcode und eine Fadenzahl für jeden
   Streifen, zum Beispiel `K4 R24 K24 Y4` (K schwarz, R rot, Y gelb).
   **Setts…** hat einige Setts zum Beginnen. Das Fenster listet alle
   Farbcodes auf.
3. **Gespiegelt**: Die Streifen gehen hinaus bis zum letzten Streifen und
   zurück, wie bei den meisten Tartans.
4. **Breite einer Fadenzahl** legt die Größe der Streifen fest.
5. Klicken Sie auf **Tartan machen**.

Das Programm erstellt eine Füllung für jede Farbe, in einer Gruppe. Ein
Tartan hat einen Fadenschnitt zwischen den Streifen einer Farbe, darum
geht kein Faden über die anderen Farben.

## Verlauf

1. Wählen Sie eine Füllung aus, dann **Bearbeiten > Sticharten > Verlauf**.
2. Fügen Sie die Farben hinzu, jede mit einem Garn und einer Stelle von
   0 % (eine Seite der Form) bis 100 % (die andere Seite).
3. Klicken Sie auf **Verlauf machen**.

Der Füllwinkel legt die Richtung der Reihen fest. Jede Reihe hat eine
Farbe, darum bleibt die Dichte gleich. Ein Verlauf mit nur einer Farbe
blendet zum Stoff aus.

## Motive

**Bearbeiten > Sticharten > Motive** öffnet die Motivbibliothek:

- **Für die Auswahl verwenden**: Linien werden zu Motivlinien,
  Satinsäulen zu Motivsäulen, Füllungen zu Motivfüllungen.
- **Aus Auswahl erstellen**: Die Stiche der ausgewählten Objekte werden zu
  einem Motiv. Die linke und die rechte Mitte ihres Rahmens sind seine
  Bezugspunkte.
- **Umbenennen** und **Löschen** ändern Ihre eigenen Motive. Designs
  behalten ihre Kopie eines Motivs.

## Farbverläufe

**Digitalisieren > Farbverläufe** mischt zwei oder mehr Farben in einer
Füllung oder Satinsäule: Lagen, deren Dichte sich von einer Seite zur
anderen ändert. Legen Sie die **Zweite Farbe** fest, dann klicken Sie auf
**Farbverlauf erstellen**. Fügen Sie weitere Lagen hinzu, und legen Sie
die Dichte jeder Lage vom Anfang bis zum Ende fest.

## Ränder

**Digitalisieren > Ränder** fügt einen dekorativen Rand (Satin,
Steppstiche, Langettenstich, Kordel oder Motive) um die Auswahl hinzu,
oder um das ganze Design, wenn nichts ausgewählt ist. Legen Sie den
**Abstand um die Objekte** fest, dann klicken Sie auf **Rand hinzufügen**.

## Knopflöcher

**Digitalisieren > Knopflöcher** macht Knopflöcher und Ösen in sieben
Formen und in Standardgrößen: eines, oder eine Reihe entlang der
ausgewählten Linie. Siehe [Knopflöcher und Ösen](buttonholes).
