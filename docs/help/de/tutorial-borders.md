# Anleitung: Ränder, Motive und Familien

In dieser Anleitung legen Sie einen dekorativen Rand um eine Form, geben
einer Linie und einer Füllung ein Motiv und fügen ein Clipart-Element
hinzu, das das Programm aus einer Familie macht.

## Das Startdesign öffnen

Klicken Sie auf [Das Startdesign öffnen](sample:decor-shapes). Es hat
einen goldenen Kreis (eine Füllung) und eine marineblaue Linie darunter.

## Einen Rand hinzufügen

1. Klicken Sie auf den Kreis, um ihn auszuwählen.
2. Klicken Sie auf **Digitalisieren > Verzieren > Ränder**. Das Fenster
   **Ränder** öffnet sich. Es zeigt ein Bild von jedem Rand.
3. Tippen Sie `hearts` in das Suchfeld, und klicken Sie auf **Herzen**.
4. Setzen Sie **Abstand um die Objekte** auf 3 mm.
5. Klicken Sie auf **Rand hinzufügen**. Ein Rand aus Herzen geht um den
   Kreis. Wenn nichts ausgewählt ist, geht der Rand um das ganze Design.

![Das Fenster Ränder](borders-window)

**Form** gibt dem Rand eine andere Form (zum Beispiel **Rechteck** um
einen Kreis), und **Größe der Stiche** macht die Stiche des Rands größer
oder kleiner.

6. Schließen Sie das Fenster **Ränder**.

## Einer Linie ein Motiv geben

Ein Motiv ist eine kleine Form, die sich entlang einer Linie (eine
Motivlinie), entlang einer Säule oder in Reihen über eine Fläche (eine
Motivfüllung) wiederholt.

1. Klicken Sie auf die marineblaue Linie, um sie auszuwählen.
2. Klicken Sie auf **Bearbeiten > Sticharten > Motive**. Das Fenster
   **Motive** öffnet sich.
3. Klicken Sie auf **Bogenkante**, dann auf **Für die Auswahl verwenden**.
   Die Linie wird als Reihe von Bögen gestickt.
4. Klicken Sie auf den Kreis, um ihn auszuwählen. Klicken Sie auf
   **Perle**, dann auf **Für die Auswahl verwenden**. Der Kreis wird als
   Reihen von Perlen gestickt.

Die Objekteigenschaften legen die **Motivlänge** und die **Motivhöhe**
fest.

## Ein Clipart-Element aus einer Familie

Eine Familie macht viele Elemente aus einer Form: einen Stern mit 4 bis 8
Spitzen, eine Blume mit mehr oder weniger Blütenblättern. Jedes Element
ist ein eigenes Design.

1. Klicken Sie im Fenster **Motive** auf **Familien…**. Das Fenster
   **Familien** öffnet sich.
2. Klicken Sie auf **Clipart**, dann auf **Sechszackiger Stern** (ein
   eingebautes Element der Familie Star).
3. Ändern Sie **Spitzen** oder **Innerer Teil**, um den Stern zu ändern.
   Das Bild zeigt das Element.

![Das Fenster Familien](borders-families)

4. Klicken Sie auf **Einfügen**. Der Stern kommt in die Mitte der
   Ansicht: eine Füllung und ein Umriss.
5. Schließen Sie die Fenster. Klicken Sie auf **Ansicht > Zeigen >
   Garnansicht**, und wählen Sie **Garnansicht** in ihrem Menü.

![Der Kreis mit seinem Rand, die Bögen und der Stern](borders-stitches)

## Wenn es nicht richtig aussieht

- **Der Rand geht um alles.** Nichts war ausgewählt. Machen Sie den
  Schritt rückgängig, wählen Sie die Form aus, und fügen Sie den Rand noch
  einmal hinzu.
- **Für die Auswahl verwenden ist grau.** Wählen Sie zuerst eine Linie,
  eine Säule oder eine Füllung aus.
- **Die Motive sind zu klein oder zu dicht.** Machen Sie die
  **Motivlänge** und die **Motivhöhe** in den Objekteigenschaften größer.
