# Anleitung: ein Design in zwei Einspannungen

In dieser Anleitung sticken Sie ein Design, das größer als der Rahmen ist,
in zwei Teilen. Es dauert etwa 20 Minuten.

## Ein großes Design erstellen

1. Wählen Sie auf dem Tab **Design** Ihre Maschine und einen Rahmen, zum
   Beispiel einen Rahmen von 240 × 150 mm.
2. Erstellen oder öffnen Sie ein Design, das breiter als der Rahmen ist,
   zum Beispiel eine Schrift von 350 mm Breite. Orange Umrisse zeigen die
   Objekte, die aus dem Rahmen gehen.

## Die Einspannungen erstellen

1. Klicken Sie auf **Einspannen > Einspannmodus**.
2. Klicken Sie auf **Automatisches Layout**. Das Programm erstellt die
   wenigsten Einspannungen, die das Design bedecken, mit einer Teilungslinie
   dazwischen. Jede Einspannung hat eine Nummer und eine Farbe.
3. Wenn die Teilungslinie durch einen Buchstaben geht, ziehen Sie die
   Linie oder ihre Knoten an eine Stelle zwischen zwei Buchstaben. Objekte,
   die nicht in eine Einspannung passen, werden an der Teilungslinie
   geschnitten.
4. Lassen Sie im Bereich **Optionen** die **Passmarken** eingeschaltet:
   Die Maschine stickt Kreuze, wo sich die zwei Einspannungen treffen.

## Die Einspannungen prüfen

Klicken Sie auf **Einspannungen ansehen**. Es zeigt jede Einspannung mit
ihren Stichen, Farben und Warnungen. Beheben Sie jede Warnung, zum
Beispiel eine Einspannung, deren Stiche aus dem Feld gehen.

## Die Dateien schreiben

Klicken Sie auf **Einspannungen ausgeben** und wählen Sie einen Ordner.
Das Programm schreibt eine Maschinendatei für jede Einspannung (name_1,
name_2), die Dateien von Design ausgeben und ein Einspannblatt (PDF) mit
der Reihenfolge und den Stellen.

## Die Einspannungen sticken

1. Spannen Sie den Stoff für Einspannung 1 ein und sticken Sie `name_1`.
   Die Maschine stickt die Passkreuze zuletzt.
2. Verschieben Sie den Stoff im Rahmen für Einspannung 2, wie das
   Einspannblatt zeigt. Einspannung 2 muss die Kreuze von Einspannung 1
   bedecken.
3. Öffnen Sie `name_2` an der Maschine. Verschieben Sie das Design an der
   Maschine, bis seine ersten Kreuze auf den gestickten Kreuzen liegen.
4. Sticken Sie `name_2`. Ziehen Sie danach die Kreuze heraus.
