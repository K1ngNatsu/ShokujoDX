# Glossar

| Wort | Bedeutung |
|---|---|
| Aktuelle Eigenschaften | Die Stichparameter, die neue Objekte bekommen. |
| Applikation | Ein Stück Stoff, das auf das Design gestickt wird: eine Platzierungslinie, ein Heftstich und ein Satin zum Abdecken. |
| Bohnenstich | Ein Steppstich, bei dem jeder Stich dreimal gestickt wird (Dreifach), für eine kräftigere Linie. |
| Deckvlies | Eine wasserlösliche Folie oben auf Handtüchern, Fleece und Samt. |
| Dichte | Der Abstand zwischen Reihen oder Satinstichen. Kleiner ist dichter. |
| Dichtekarte | Eine Ansicht, die das Design nach den Garnlagen färbt. |
| Digitalisieren | Ein Stickdesign machen: Formen, Sticharten, Stickreihenfolge und Einstellungen. |
| Einspannung | Ein Teil eines Designs, das größer als der Rahmen ist. |
| Einstichpunkt | Eine Stelle, an der die Nadel durch den Stoff geht. |
| Fadenschnitt | Die Maschine schneidet das Garn. |
| Farbvariante | Ein Satz Farben eines Designs. Ein Design kann mehr Farbvarianten haben. |
| Farbwechsel | Die Maschine stoppt oder geht zu einer anderen Nadel, um ein anderes Garn zu sticken. |
| Füllung | Reihen von Stichen, die eine Fläche bedecken. |
| Garnkarte | Die Liste der Farben einer Garnmarke. |
| Grundlage | Eine leichte Füllung unter dem Design, die den Flor von Handtüchern und Fleece niederhält. |
| Heftstich | Stiche, die den Applikationsstoff vor dem Satin zum Abdecken halten. |
| Maschinendatei | Die Einstichpunkte und Funktionen eines Designs für eine Maschine (DST, PES, VP3 und andere). |
| Motiv | Ein kleines Stichmuster, das sich entlang einer Linie, einer Säule oder in einer Füllung wiederholt. |
| Objekt | Ein Teil eines Designs: eine Linie, eine Säule, eine Füllung, eine Applikation, Schrift und mehr. |
| Passmarken | Kreuze, die zwei Einspannungen oder eine Strassschablone ausrichten. |
| Projekt | Die Datei dieses Programms (.embproj), mit allen Objekten und Einstellungen. |
| Rahmen | Der Rahmen, der den Stoff auf der Maschine hält. Das Feld ist, wohin die Nadel gehen kann. |
| Randkontur | Ein Rand oder eine Lücke um Objekte, aus den Objekten darunter ausgeschnitten. |
| Satin | Glatte Stiche von Seite zu Seite einer Säule. Sie glänzen. |
| Säule | Eine Satinsäule: Stiche quer über eine Form von einer Seite (Schiene A) zur anderen (Schiene B). |
| Sett | Die Streifen eines Rapports eines Tartans, zum Beispiel K4 R24 K24 Y4. |
| Sprung | Eine Bewegung des Rahmens ohne Stich. |
| Steppstich | Stiche, einer nach dem anderen, entlang einer Linie. |
| Stich | Das Garn zwischen zwei Einstichpunkten. |
| Stichcursor | Eine Marke auf einem Stich, um das Design Stich für Stich zu prüfen. |
| Stichobjekt | Stiche aus einer Maschinendatei oder einem Fotostich, so gestickt, wie sie sind. |
| Stickreihenfolge | Die Reihenfolge, in der die Objekte gestickt werden. Ein Objekt, das später gestickt wird, liegt oben. |
| Stickvlies | Ein Vlies unter dem Stoff. Schneidvlies für Strickstoffe, Reißvlies für gewebte Stoffe. |
| Stil | Ein Satz Stichparameter mit einem Namen. |
| Stopp | Die Maschine stoppt, damit Sie etwas von Hand tun können. |
| Tatami | Eine Füllung aus geraden Reihen in einem Muster, das keine Linien zeigt. |
| Teilen | Zusätzliche Einstichpunkte in langen Stichen, damit sie nicht hängen bleiben. |
| Unterfaden | Das Garn unter dem Stoff. Es verschlingt sich an jedem Einstich mit dem Oberfaden. |
| Unterlage | Stiche unter den oberen Stichen, die den Stoff halten und die oberen Stiche anheben. |
| Vektor | Eine Form ohne Stiche. Umwandeln macht daraus Stickerei. |
| Verbindungsstiche | Stiche, die von einem Teil zum nächsten gehen, unter Stichen, die sie bedecken. |
| Vernähstich | Kleine Stiche, die das Garn am Anfang oder Ende eines Objekts halten. |
| Vlies | Material, das den Stoff beim Sticken hält: Stickvlies und Deckvlies. |
| Zugausgleich | Zusätzliche Breite, weil die Stiche den Stoff quer zu ihrer Richtung zusammenziehen. |
