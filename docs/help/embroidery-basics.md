# Embroidery basics

This topic tells how machine embroidery works, and what the program does
for you. The words in **bold** are in the [Glossary](glossary) too.

## How the machine sews

An embroidery machine moves the hoop under the needle. At each **needle
point** the needle goes down through the fabric, and the top thread
locks with the **bobbin** thread under the fabric. A **stitch** is the
thread between two needle points.

- The machine sews one color at a time. At a **color change** it stops
  (a home machine) or changes to another needle (a multi-needle machine).
- Between two parts that are far apart, the machine **trims** (cuts) the
  thread, or **jumps** (moves with no stitch), or sews a **travel**
  stitch that the next stitches cover.
- A **stop** lets you do something by hand, for example put on
  appliqué fabric or foam.

A machine file (DST, PES, VP3 and others) is the list of the needle
points and of these functions. The machine cannot change the design.
That is why you keep the project file of this program.

## What digitizing is

Digitizing is the work of making a design from shapes: you decide the
kind of stitch of each shape, the direction of the stitches, the order
of the shapes and the settings. The program then makes the needle
points.

- **Running stitches** (lines) are for outlines and small details.
- **Satin columns** are for borders, narrow shapes and letters, up to
  about 10 mm wide. The thread goes from one side to the other, so it
  shines.
- **Fills** (tatami) cover large areas with rows of stitches.

See [Objects and stitches](objects-and-stitches).

## Fabric and stabilizer

Stitches pull on the fabric. Without help, the fabric puckers and the
design changes shape.

- A **stabilizer** (backing) under the fabric holds it. Use a cut-away
  backing for knits (T-shirts, polo shirts, sweatshirts), and a tear-away
  backing for woven fabric that does not stretch.
- A **topping** (a thin water-soluble film) on top of towels, fleece and
  velvet keeps the stitches on top of the pile.
- Hoop the fabric and the backing together, tight and flat, but do not
  stretch the fabric.

**Design > Fabric** tells the program the fabric. The program then sets
the density, the underlay and the pull compensation, and the worksheet
shows the backing and topping. See [Fabrics, styles and
templates](fabrics-and-styles).

## Density, underlay and pull

- **Density** is the distance between rows or satin stitches (0.4 mm is
  usual). Too dense makes the design stiff, and the needle can break.
  Too open lets the fabric show.
- **Underlay** is a layer of stitches under the top stitches. It holds
  the fabric flat and lifts the top stitches.
- **Pull compensation**: the stitches pull the fabric in across their
  direction, so a shape sews narrower than you drew it. The program
  makes the shape a little wider. Stretchy fabric needs more.
- Objects on top of each other add layers of thread. **View > Density Map** shows where too many layers build up.

## Size and scale

A design is made for one size. When you scale a design object in this
program, the program makes the stitches again, so the density stays
correct. A machine file that you scale on the machine keeps the same
number of stitches, so it gets denser or more open.

- Small text below about 5 mm high does not sew well.
- Details that are smaller than about 1 mm sew as a knot of thread.
- The stitch count sets the sew time: the status line and Design info
  show the time at the speed of your machine.

## The order of the work

1. Select the machine, the hoop and the fabric (Design tab).
2. Draw the objects, or start from a picture or lettering.
3. Set the stitch types and the settings (Object Properties).
4. Set the sew order: the background first, the details and the
   outlines last. Keep each color together, so there are few color
   changes.
5. Check the design: the stitch player, the thread look, Design info and
   the density map. See [Checking a design](checking).
6. Write the machine file, and sew a test on the same fabric and backing.

## Test sew-outs

Always sew a test on a piece of the same fabric, with the same backing.
Look for puckers, gaps between objects, loose stitches and thread that
builds up. Change the design and test again. [Questions and
problems](troubleshooting) helps with the common faults.
