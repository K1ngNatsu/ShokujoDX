# Tutorial: a name on an arc

In this tutorial you put a name on an arc, change the font, and move one
letter.

## Add the lettering

1. On the **Lettering** tab, click **Lettering**.
2. Click on the canvas where the text starts.
3. Type the name in the Lettering window.
4. Select a font. The list shows a preview and the size range of each
   font. Embroidery fonts sew best in their size range.
5. Set the **Height**, for example 25 mm.
6. Click **OK**.

## Put the name on an arc

1. Select the lettering.
2. In Object Properties, set the **Baseline** to **Arc over** (the text
   is on the top of a circle) or **Arc under** (the text is under it).
3. Set the **Radius** to make the arc flatter (larger) or rounder
   (smaller).

**Lettering on Line** puts the text on a line that you draw: select the
lettering and the line, then use the command.

## Change the size and the spacing

- To make the letters larger or smaller, change the **Height** in Object
  Properties. Or drag a corner handle of the selection.
- **Letter spacing** changes the space between all letters.
- To move one letter, click **Reshape** and click the letter. Drag the
  letter, or change its spacing and angle in Object Properties.

## Edit the text

Double-click the lettering, or right-click it and select **Edit text**.
Esc closes the Lettering window with no change.

## The lettering kiosk

The kiosk is one large screen for a shop. Click **Lettering > Lettering Kiosk** (or the link on the start page).

1. **Product**: select the product, its color and the place of the
   design. The product sets the fabric, so the stitches suit it.
2. **Text**: type the name, and set the size and the line (straight, arc
   over or arc under).
3. **Font**: select an embroidery font.
4. **Thread color**: select a color. The program uses the nearest thread
   of the thread chart.

The preview shows the name on the product with the 3D thread look. A
message tells you if the name is larger than the place on the product.
Then click **Save**, **Output Design**, **Send to USB** or **Save
picture**. **New name** starts again. **Exit kiosk** goes back to the
normal window with the design.

To start the program in the kiosk, add `--kiosk` to the command of its
shortcut, for example `"ShokujoDX.exe" --kiosk`.

## More lettering tools

- **Monogram** makes two or three letters with a border and ornaments.
- **Team Names** makes one design with a different name in each copy.
- **Fonts** opens the font list (thirty embroidery fonts come with the
  program). Convert a TrueType or OpenType font to an embroidery font
  there.
