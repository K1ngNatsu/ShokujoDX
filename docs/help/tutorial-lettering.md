# Tutorial: a name on an arc

In this tutorial you put a name on an arc, set its size and its arc, and
learn how to change one letter.

## Add the lettering

1. Click [Open the start design](sample:lettering-start). A construction
   point shows where the name starts.
2. Click **Lettering > Lettering > Lettering**.
3. Click the construction point. The **Lettering** window opens.
4. Type the name, for example `Anna`. The name shows on the canvas while
   you type.
5. Keep the font **Block Sans**, or select another font in the list. The
   list shows a preview, the size range and the quality score of each
   font. Embroidery fonts sew best in their size range.
6. Set **Height** to 25 mm. This is the height of the capital letters.
7. Click **OK**. The lettering is selected.

![The Lettering window](lettering-window)

## Put the name on an arc

1. In Object Properties, set **Baseline** to **Arc over**: the name is on
   the top of a circle. (**Arc under** puts it under a circle.)
2. Set **Radius** to 80 mm. A larger radius makes the arc flatter, a
   smaller one makes it rounder.
3. Push **Esc**, then click **View > Show > Thread Look**, and select
   **Thread Look** in its menu.

![The name on an arc](lettering-arc)

Do not make the arc too round for the height: the feet of the letters
come near each other, and the thread builds up there. Design Info then
shows a warning.

**Lettering on Line** puts the text on a line that you draw: select the
lettering and the line, then click **Lettering > Lettering > Lettering on
Line**.

## Change the size and the spacing

- To make the letters larger or smaller, change the **Height** in Object
  Properties. Or drag a corner handle of the selection.
- **Letter spacing** changes the space between all letters.
- To move one letter, click **Digitize > Select > Reshape** and click the
  letter. Drag the letter, or change its spacing and angle in Object
  Properties.

## Edit the text

Double-click the lettering, or right-click it and select **Edit text**.
Esc closes the Lettering window with no change.

## The lettering kiosk

The kiosk is one large screen for a shop. Click **Lettering >
Personalize > Lettering Kiosk** (or the link on the start page).

1. **Product**: select the product, its color and the place of the
   design. The product sets the fabric, so the stitches suit it.
2. **Text**: type the name, and set the size and the line (straight, arc
   over or arc under).
3. **Font**: select an embroidery font.
4. **Thread color**: select a color. The program uses the nearest thread
   of the thread chart.

The preview shows the name on the product with the 3D thread look. A
message tells you if the name is larger than the place on the product.
Then click **Save**, **Output Design**, **Send to USB** or **Save
picture**. **New name** starts again. **Exit kiosk** goes back to the
normal window with the design.

To start the program in the kiosk, add `--kiosk` to the command of its
shortcut, for example `"ShokujoDX.exe" --kiosk`.

## More lettering tools

- **Monogram** makes two or three letters with a border and ornaments.
- **Team Names** makes one design with a different name in each copy.
- **Fonts** opens the font list (68 embroidery fonts come with the
  program, each with a quality score). Convert a TrueType or OpenType
  font to an embroidery font there.

## If it does not look right

- **The status line shows a warning after the arc.** The arc is too
  round. Increase the **Radius**.
- **OK is gray.** The window is empty: type the name first.
- **Thin columns, or parts are lost.** See step 5 above.
