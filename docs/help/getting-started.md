# Getting started

ShokujoDX makes embroidery designs. You draw shapes, type
lettering or start from a picture, and the program makes the stitches.
Then you write a file for your embroidery machine.

If embroidery is new to you, read [Embroidery basics](embroidery-basics)
first. To learn by doing, start with [Tutorial: a patch from a
picture](tutorial-patch).

## The start page

The start page shows when the program starts. It has:

- **New design**, **New from Template**, **Open** and **Picture to Design**.
- Your recent designs, with a picture of each. Click one to open it.
- The tutorials, and a box where you can ask a question.
- **Simple Mode** and the **Lettering Kiosk** (for shops).

**Help > Start Page** shows it again. Clear **Show at start** if you do
not want it when the program starts.

To open a file, you can also drag it onto the window: a design or a
machine file opens in a new tab, an SVG or PDF goes into the design, and a
picture becomes the backdrop.

## The window

- **The File button** (top left) opens the file menu: new, open, save,
  import, export, options and exit. Next to it are **New**, **Open**,
  **Save**, **Undo** and **Redo**.
- **The ribbon** has the commands in tabs. See "Where to find the
  commands" below.
- **The design tabs** under the ribbon show each open design. A **+**
  makes a new design.
- **The canvas** in the middle shows the hoop and the design. See [The
  canvas and the selection](canvas).
- **The panels** on the right show the selected object (Object
  Properties), the sew order (Sequence), the threads, the styles, the
  design info and more. Each panel closes with its ×. **View > Panels**
  opens it again.
- **The property bar** under the ribbon has the settings of the active
  tool, for example the stitch length of new lines.
- **The status line** at the bottom tells you what to do next, and shows
  the number of objects, colors, stitches and trims, the sew time and the
  zoom.

## Where to find the commands

Each ribbon tab has the commands of one kind of work:

| Tab | What it has |
|---|---|
| Digitize | The select tools, and the tools that draw lines, fills, columns, shapes and appliqué. Borders, buttonholes and blends. |
| Lettering | Lettering, fonts, alphabets, monograms, team names, keyboard designs and the kiosk. |
| Artwork | Pictures (Picture to design, the backdrop, trace, click to stitch) and vector artwork (import, draw, convert, shaping, border traces and offsets). |
| Specialty | Cross stitch, rhinestones, cutwork, quilting, puff and laydown. |
| Edit | Copy and paste, select, split and join, change shapes and lines, stitch types and machine functions. |
| Arrange | Turn, mirror, align, space, copies, group, lock and the sew order. |
| Color | Threads, thread charts, colorways and the fabric color. |
| View | What shows on the canvas, the stitch player and the stitch cursor, filters, zoom and the workspace. |
| Design | Machine, hoop, fabric, styles, the design library, templates, repeats, the product and the output files. |
| Hooping | Designs that are larger than the hoop. |
| Help | Help topics, tutorials, the start page and simple mode. |

The help has a topic for each tab, with all of its commands: see **The
ribbon** in the contents of the help.

When the window is narrow, a panel of the ribbon folds into one button
with its name and an arrow. Click the button to see the commands of the
panel. Double-click a tab to hide the ribbon and get more space; click a
tab to show it again.

## Find a command

- **Ctrl+K** opens **Find a Command**: type a part of the name of a
  command, select it with the arrow keys and push **Enter**. All ribbon
  commands are in it, with their shortcuts.
- **Space** does the last ribbon command again.
- **F6** puts the keyboard on the ribbon. **Tab** and **Shift+Tab** go
  from button to button, **Enter** runs one, **Esc** goes back to the
  canvas.
- A screen reader (for example Narrator or NVDA) reads the buttons and
  the canvas.

## Text size, contrast and language

**Options** (View tab, or the File menu) sets:

- **Text size**: all text and buttons from 90 % to 200 %. **Ctrl+Plus**,
  **Ctrl+Minus** and **Ctrl+0** change it too.
- **High contrast**: black or white panels with strong lines.
- **Language**: English, Deutsch, Español or 日本語. The help topics are
  in English.

See [Options](options) for all the settings.

## Simple mode

Simple mode shows fewer tools, with larger buttons: the tools to draw a
design, letter it and send it to the machine. It also hides the panels
that you do not need for these tasks.

- To turn it on or off, click **Help > Simple Mode**, or use the box on
  the start page or in Options.
- In simple mode, **View > Simple Mode** turns it off again.
- All commands of simple mode are on the full ribbon too.

## Before you start a design

1. On the **Design** tab, select your machine. The machine sets the file
   format (for example VP3 for Husqvarna Viking, PES for Brother, DST for
   most commercial machines).
2. Select your hoop on the **Design** tab. The canvas shows the hoop. The
   top of the canvas is the back of the machine.
3. If you know the fabric, click **Design > Fabric**. The fabric changes
   the density, the underlay and the pull compensation of the objects.

See [Machines and hoops](machines-and-hoops) and [Fabrics, styles and
templates](fabrics-and-styles).

## Save and undo

- **Ctrl+S** saves the design as a project file (`.embproj`). A project
  keeps all objects and settings, so you can change them later.
- **Ctrl+Z** undoes the last change. **Ctrl+Y** does it again. The
  tooltips of Undo and Redo tell what they change.
- The program saves a backup of each changed design every 2 minutes. If
  the program stops, it offers the backups at the next start.
- A machine file (DST, PES, VP3 and others) has only the stitches. Keep
  the project file to make changes.

## Get help

- Put the pointer on a button and wait: a short text tells what it does.
- Put the pointer on a button and push **F1**: the help opens at that
  command.
- Push **F1** while the pointer is on a window (for example Offsets or
  the Lettering window): the help opens at the topic of that window.
- **Help > Help** shows all the topics. Type a question in the search
  box, for example "how do I make the letters larger". The answer shows
  first, and the other topics with your words show under it.
- Click a link in a topic to go to another topic. **Back** goes to the
  topic before.
- [Questions and problems](troubleshooting) has the answers to common
  problems.
