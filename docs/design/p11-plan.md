# Plan: roadmap phase P11 (features of other programs)

Date: 2026-10-25 · Status: Accepted (owner request, 2026-10-25). Milestones 1 to 8 done in software.

## Goal

P1 to P10 follow the feature inventory of the reference product
(`docs/design/feature-inventory.md`). Other programs have useful features that
the reference product does not have, or that the inventory did not list. P11 adds
them. The owner selected this list on 2026-10-25, from a review of the
public features of these programs:

- Ink/Stitch (GPL-3.0, an extension for Inkscape),
- Other free and commercial embroidery programs,
- Reference-product features that the inventory did not list.

Sources for what each feature does: the public documentation of each
program, in our own words (clean-room rule). Ink/Stitch is free software
with the same license as this project: an algorithm can be ported from it,
with a header comment that gives the source file and the commit hash
(spec, rule 4). The other programs are closed source: describe what their
features do, and do not copy their code, files or assets (spec, rule 3).

The exit test of the phase: the sew-outs and the user tests of each
milestone below pass.

## Order

The small features that help each design come first. Content work (fonts
and thread charts) comes next: it needs few code changes, and the owner
decides the source of the thread colors. The new stitch types come before
free-standing lace and quilting, because these use them. Features for a
machine that the owner does not have come last, and wait for a tester with
such a machine (the rule of P9).

Then the exit test of the phase: the exit tests of each milestone pass.

## Not in this phase

| Item | Reason |
| --- | --- |
| The font files of other embroidery programs | No public description of the formats; reverse engineering is not allowed (spec, rule 3). Revisit if a maker publishes one. |
| WiFi and cloud send to machines (the apps of machine makers) | No maker publishes a protocol (ADR 0036). Send to USB does the job. |
