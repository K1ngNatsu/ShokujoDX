# Plan: roadmap phase P10 (polish and assistance)

Date: 2026-10-24 · Status: Accepted. Milestones 1 to 6 done in software; Milestone 7 done in software (German, Spanish and Japanese); Milestone 8 done in software (the first CI run and the exit test are open). Milestone 9 (assistant) is benched (owner decision).

## Goal

Make the program complete and easy to start with (roadmap P10): the
small features that the audits of the earlier phases moved here, a 3D
thread look, a start page and help, a simple mode and a lettering kiosk,
accessibility and translations, and installers for Windows, macOS and
Linux. The exit test of the roadmap: the 15-minute patch test (P2) passes
for users of Windows, macOS and Linux.

The owner started this phase on 2026-10-24. The exit tests of P2 and P3
(users, with the test package), P5, P6, P7 and P9 (sew-outs) and part 2
of P8 (the Topaz 20 reads a stick) are still open. Milestones 6 and 7 of
P9 wait for a tester with a sequin, bead, chenille or Schiffli machine.

Sources for what each tool does: the public documentation of commercial
embroidery products, in our own words
(clean-room rule).

## Order

Each milestone ends with something a user can try. The small features
come first, because the help (Milestone 4) and the translations
(Milestone 7) must include them. The installers come last, because they
package all the rest.
