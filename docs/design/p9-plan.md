# Plan: roadmap phase P9 (specialty decoration)

Date: 2026-10-24 · Status: Accepted. Milestones 1 to 5 done in software (audit: `docs/design/roadmap.md`, "Audit of P9"); the sew-outs of 1, 2 and 5 on the Topaz 20 (with a cut template) are open. Milestones 6 and 7 wait for a tester with such a machine.

## Goal

Decoration that is not plain embroidery (roadmap P9): cross stitch,
rhinestones (bling), sequins and beads, chenille and Schiffli. The exit
test of the roadmap: for each device, a design sews or cuts correctly on
a real machine.

The roadmap says that each part starts only when an owner of such a
machine can test it. The owner sews on a Husqvarna Viking Topaz 20 (no
sequin, bead, chenille or Schiffli device). Thus this plan puts first the
parts that the owner can test:

- Cross stitch sews on each embroidery machine.
- A rhinestone template is cut on a vinyl or craft cutter, or printed at
  real size to check it with a ruler and the stones.

Sequins, beads, chenille and Schiffli need a device that the owner does
not have. Their milestones start only when a tester with such a machine
is found, and only for formats with a public description (the
clean-room rule).

The owner started this phase on 2026-10-24. The exit tests of P2 and P3
(users, with the 0.1.0 test package), P5, P6 and P7 (sew-outs) and part 2
of P8 (the Topaz 20 reads a stick) are still open.

Sources for what each tool does: the public documentation of commercial
embroidery products, the public format notes of pyembroidery (MIT,
commit `c16d1b4`) and common practice (cross-stitch charts, rhinestone
stone sizes), in our own words (clean-room rule).

## Order

Each milestone ends with something a user can try.

| # | Scope | Exit test |
| --- | --- | --- |
| 1 | **Cross-stitch objects.** A new object kind (ADR 0038): crosses on a grid of square cells, in one thread color. Each cell has a full cross, a half cross (`/` or `\`), a quarter cross or a three-quarter cross; backstitch lines go along the cell sides and diagonals. The stitches: the crosses row by row (the bottom legs out and the top legs back, so all top legs go the same way; or a zigzag with no travel stitches), then the backstitch lines. A Specialty tab: tools to paint cells with the current color, to erase cells and to draw backstitch lines; the cell size (mm, or the count of an Aida fabric); the grid shows while a tool is on. Convert fills, vectors and appliqué to cross stitch (each cell whose center is inside). Object Properties: cell size, passes, order. | Unit tests; a cross-stitch motif of the corpus sews on the Topaz 20 with crosses that meet at the cell corners. |
| 2 | **Picture to cross stitch, and charts.** A picture becomes cross-stitch objects: a grid over the picture, the number of colors, the thread chart, the colors matched to it, half crosses at the edges as an option. A chart PDF for hand cross stitch: a symbol for each color in each cell, the grid with a heavy line each 10 cells, a key (symbol, thread, number of stitches) and the size on the fabric for each Aida count. | A picture becomes a cross-stitch design that sews; the chart prints. |
| 3 | **Rhinestones (bling).** A stone palette: stone sizes SS6 to SS34 with their diameters, and colors. A bling object kind (ADR 0039): stones at points. Tools: single stones, a stone run along a line (spacing, from end to end), a stone fill of a closed shape (rows, or rings that follow the outline), stones along the outline of lettering. Overlap check: stones that touch or are nearer than the gap show red; remove overlaps. The stones show with their size and color on the canvas. | A bling design with runs, fills and lettering, with no overlaps. |
| 4 | **Rhinestone templates.** Template output: a hole for each stone (stone diameter plus a clearance for the template material), as SVG and DXF at real size, and a PDF at real size; registration marks. The worksheet lists the stones of each size and color. `emb-cli bling`. | A template cut on a vinyl cutter (or printed at real size) takes the stones at the places that the design shows. |
| 5 | **Mixed decoration and multi-decoration output.** One design with embroidery and rhinestones. Output design writes a file for each process: the machine file without the stones, the stone template, and a worksheet that gives the order of the processes. Marks that sew on the fabric (or print on the template) to put the template at the correct place on the sewn design. | A design with embroidery and stones: the template aligns with the sewn design. |
| 6 | **Sequins and beads.** Starts when a tester with a sequin or bead device is found. A sequin palette (size, shape), single and twin sequins, sequin runs and fills; the sequin mode of DST (the public description in pyembroidery); beads if a public format description is found. | The tester's machine sews a sequin run. |
| 7 | **Chenille and Schiffli.** Starts only when a tester with such a machine is found and a public description of its file format is known. No such description is known today. | The tester's machine sews the design. |

Then the exit test (roadmap P9 exit): for each device that a tester has,
a design sews or cuts correctly on the real machine.

## Progress

| # | State | Notes |
| --- | --- | --- |
| 1 | Done in software; sew-out open | New object kind `ObjectKind::CrossStitch` (ADR 0038, `emb_model::cross`): a grid (corner and two cell vectors, so all transforms are exact), the cells (full, half `/` and `\`, quarter and three-quarter crosses at a corner; saved as `[col, row, "x"]`), backstitch lines on the half grid, settings (each leg once or 3 times, order, backstitch once or 3 times). Design edits: paint (a cell has one color: it leaves the other objects on the grid; empty objects go), erase, lines, break apart (cells that touch, also at a corner). Stitches (`emb_stitch::cross`): needle points only at cell corners and centers. Zigzag (the default): the two legs in turn out and back, no travel between the cells. Rows: all top legs the same way, a travel stitch along each cell side. Each row goes out to its far end (partial crosses on the way) and back; a three-quarter cross sews the way that ends where the next piece starts; a quarter cross goes out to the center and back. Pieces join with travel stitches along the cell sides (at most 3 cells, a cell with crosses on one side at least, fewer stitches on the edge preferred); else a trim. Backstitch lines join into long lines, a needle point at each half-grid point, no stitch longer than 4 mm. App (`cross.rs`): a Specialty tab with the Cross stitch tool (drag to paint; Shift+drag erases), Erase cells, Backstitch (click corners and centers; Enter, Esc or a right click ends the line) and To cross stitch (fills, appliqué, satin columns and closed vectors: each cell whose center is inside). The property bar: the part and the cell size (mm, or an Aida count; a new size starts a new grid). The grid shows while a tool is on (a darker line each 10 cells), with the cell under the pointer and the cross that it gets. Object Properties: counts, cell size (all objects on the grid), legs, order, backstitch. Corpus design `cross-stitch` (a heart on a 2.5 mm grid with all kinds of crosses, a backstitch frame and a bar in rows): 535 stitches, 6 trims (3 at the color changes). Known limit for the sew-out to judge: a travel stitch along a cell side shows between the crosses (crosses touch only at their corners). |
| 2 | Done in software; sew-out open | Picture to cross stitch (`emb_art::cross`): 6 × 6 samples in each cell of the grid; clear pixels count as empty; a cell three quarters filled gets a full cross, and (an option, on by default) a cell at an edge with its filled samples on one side of a diagonal gets a three-quarter cross toward that side; the mean colors of the cells are reduced to 2 to 32 colors (`reduce`, or kept as they are if the picture has that few), and groups of fewer than 3 cells of one color take the color round them (fewer trims). It is a third choice in the Picture to design wizard ("Cross stitch": Picture, Background, Cross stitch, Finish), so the background removal and the cut-out work for it; the Cross stitch step has the design width, the cell size (mm or Aida), the thread colors, three-quarter crosses and noise smoothing, with the stitches in the preview; Finish matches the colors to the chart of the Threads panel. The grid is the grid of the cross-stitch tools. Specialty > Picture to cross stitch opens the wizard set to cross stitch. Chart (`emb_render::cross_chart`): page 1 has the size in cells, on the machine and on Aida 11, 14, 16 and 18, the key (symbol, color, thread, full and partial crosses, lines) and a small picture of the whole chart; then the chart pages: 3 mm cells with a symbol on a tint of the thread color (32 drawn symbols; partial crosses smaller, in their part of the cell), a darker line and a number each 10 cells, arrows at the center, the backstitch lines; a large chart goes on more pages (60 × 85 cells on A4). Specialty > Chart (PDF, the paper of the output profile) and `emb-cli chart`. Corpus design `cross-picture` (the portrait, 50 × 60 mm, 6 colors): 1280 stitches, 35 trims. The PDF pages were checked by eye in a PDF viewer. |
| 3 | Done in software | New object kind `ObjectKind::Bling` (ADR 0039, `emb_model::bling`): one stone (SS6 to SS34 with their diameters, 12 common colors or any color) and a layout: single stones, a run along a path (from end to end, or evenly round a closed path), or a fill of a closed shape (rows at an angle with each other row moved half a step, or rings a stone apart from the outside in, with one stone in a small middle part); the gap between stone edges (0.5 mm by default). Runs and fills keep their paths, so Reshape and the transforms work and the stones keep their size. `Design::stones` places all stones in sew order: a stone whose edge is nearer than 0.2 mm to a stone before it is left out when its object has Remove overlaps (the default), else both are marked. The stones sew nothing. App (`bling.rs`): Specialty > Rhinestones with the Stone tool (each click a stone; into the selected object of single stones), Stone run and Stone fill (drawn as a line or a shape), Outline to stones, Center line to stones (one line of stones along the middle of each stroke, for lettering) and Fill with stones; the property bar has the stone, the gap and the fill. The canvas draws each stone as a disk in its color (dark stones with a light edge), overlaps with a red ring, the selected ones with a blue ring; the stones are kept until a rhinestone object changes. Object Properties: the number of stones (and how many are left out), stone, gap, fill, Remove overlaps. Corpus design `rhinestones` (a sewn frame, "BLING" along center lines, a heart in rows, a circle in rings and a run round it, three single stones): more than 150 stones with no overlap. The rows test: no two stones nearer than a step. |
| 4 | Done in software; a cut template open | The template (`Design::stone_template`): a hole for each stone of `Design::stones` (so the left-out stones have no hole), the stone diameter plus a clearance (0.3 mm by default, a setting in the property bar of the stone tools), and four registration crosses 8 mm outside the box of the holes; in design mm with the design rotation (as the canvas; the hoop angle is how the design sits in the hoop, not on the garment). Files (`emb_formats::stones`): SVG at real size with a group of circles for each kind of stone (its title has the number of holes and their size) and a group of marks; DXF R12 with a `CIRCLE` for each hole on a layer for each kind of stone and the marks as `LINE`s on the layer `MARKS`. PDF (`emb_render::stone_sheet`): a key page (each kind of stone: color, size, hole, number; how to use the template) and the template at full size with a 50 mm scale line, on more sheets if it is larger than the paper (each hole on the sheet with its center). Specialty > Template (SVG, DXF or PDF) and `emb-cli bling` (`--clearance`). The production worksheet draws the stones on its picture (the picture fits the stitches and the stones) and lists the stones of each size and color. The SVG reads in usvg at its size; the PDF pages and the worksheet were checked by eye in a PDF viewer. |
| 5 | Done in software; sew-out open | Template marks (Specialty > Template marks, `Design::add_template_marks`): a running-stitch object with four crosses, 8 mm outside the stones, at the end of the sew order in its own thread ("Template marks (pull out)", pink); each cross is one line, so the marks add one trim each. The design keeps which object it is (`Design::template_marks`); the template takes its marks from that object (`Design::sewn_mark_centers`), so a moved mark moves the template mark too; the command again puts the crosses back at the corners of the stones. Output design (and `emb-cli output`): for a design with stones, also `<name> template.svg` and `<name> template.pdf` (an output profile choice, on by default, with the hole clearance); the machine file has the embroidery and the marks, no stones. The production worksheet has the template files in its file list, the marks in its picture, and "Order of work" (`sheet::process_steps`): sew (the marks last), cut the template and brush the stones in, pick them up with transfer tape and mark the crosses on it, put the tape on the sewn crosses, press, pull out the mark threads. The corpus design `rhinestones` has its marks now (its golden snapshot changed: 573 stitches, 2 colors, 5 trims); a golden test checks that each template mark is a sewn cross of the same design point. Multi-decoration machine formats (Dahao DHE and others): no public description, not made. |
