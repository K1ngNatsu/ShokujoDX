## Goal

The owner published v0.2.0 and sent a list of changes and one bug
(2026-11-16). This plan puts them in six stages. Stage 1 is a quick
release (v0.2.1), because friends of the owner could not start the
program. Stages 2 to 6 make v0.3.0.

The owner's answers to the questions of 2026-11-16:

- The friends saw nothing at all: no window and no message.
- Vertical text is stacked letters: each letter upright, from top to
  bottom (or bottom to top). A turned line is possible already (turn the
  text box).
- A new install asks for the machine on the first start, with the
  Generic machine selected until the user picks one.
- The machine library has Brother and Baby Lock, Janome and Elna,
  Husqvarna, Pfaff and Singer, Bernina, and commercial multi-needle
  machines (Tajima and others).

Decisions that the owner accepted with the plan:

- Endless drag is for the view drags (pan and zoom), not for object
  moves. Pen and tablet input does not wrap.
- Outside sketch mode a sketch can move, turn and mirror, but not scale.
- A font with no bold or italic file gets a made one (slant, wider
  columns), not a disabled button.

## Stage 1: the start bug and the installer (v0.2.1)

The test PC (Windows 11 24H2, Intel Core i5-10400 with UHD 630
graphics, 16 GB) showed nothing when the program started. The program
has no console, so an error of the window or of the graphics goes
nowhere and the program stops with no message. A PC with no graphics
driver of its maker (only the basic display driver of Windows), or an
old one, has no graphics adapter that the renderer accepts.

1. The C runtime is in the program (static CRT), so the program does not
   need `VCRUNTIME140.dll`. A CI step checks the imports of the program.
2. Renderer fallbacks: DirectX 12 or Vulkan, then OpenGL, then the
   software renderer of Windows (WARP). If a renderer fails at the start,
   the program starts again with the next one. If all fail, a message
   box tells the reason and what to do, and the program writes a log.
3. The first start checks the graphics. If only a software adapter
   works, the program tells the user to install the graphics driver of
   the maker, with a link.
4. `ShokujoDX.exe --diagnose` writes a report of the graphics adapters
   and the start, for a user who reports a problem.
5. The installer finds an older version (installed for one user or for
   all users), shows "Upgrading from …", removes it with no questions,
   then installs. The settings and the projects stay (they are not in the
   program folder). A CI step installs v0.2.0, then the new version, and
   checks that one version is installed and that the settings stay.

## Stage 2: first start and saved preferences

6. The View options (Thread Look, the 3D look, grid, rulers and the
   others) are kept between sessions.
7. A first-start step asks "Which machine do you have?". The Generic
   machine and its hoops are the default in place of the Topaz 20.

## Stage 3: canvas

8. Endless drag, as in Blender: during a pan or zoom drag, the cursor
   goes to the other side of the window at an edge, so the drag does not
   stop.

## Stage 4: parametric sketch

9. Each new sketch has a fixed construction point at (0, 0).
10. Outside sketch mode a sketch object does not scale (move, turn and
    mirror stay).
11. Objects made from a sketch stay locked to it until Break Apart: they
    move with the sketch and do not move, scale or change nodes alone.
    Their stitch settings (type, angle, density, color) can change.
12. The Sketch tab groups its commands as the reference CAD program
    does: drop-down buttons for Line, Circle, Arc, Rectangle, Fillet and
    Text; compact grids for Modify, Pattern and Constrain; Insert, Format
    and Finish groups. Only commands that the program has.

## Stage 5: lettering

13. Bold, Italic and Underline. A TrueType family uses its Bold and
    Italic files if it has them; else the program makes the style (italic:
    a slant of about 12°; bold: wider satin columns or larger fill
    shapes). Embroidery fonts get the made styles. Underline is a satin
    bar or a run under each line, with a gap and a thickness.
14. Text direction: stacked, top to bottom or bottom to top. Each letter
    stays upright on one vertical center line. Stacked text uses a
    straight baseline (no arc or envelope).

## Stage 6: machine library

15. Machines of the brands above with their hoops, file format, stitch
    length limit, speed and needles, from public data only (manuals and
    specification pages), with the source of each value in the data
    file. A Generic profile for each format (PES, JEF, VP3, XXX, EXP,
    DST and others).
16. An Add My Machine window: format, hoops (type the sizes or pick
    standard hoops), needles and speed; save it, and export it to share.
    The first-start step of Stage 2 then shows the full list.
